# 派遣中の選択イベント

## 初回仕様

これから出発する商店街・郊外への派遣に、1日目終了時の出来事を追加する。発生条件は固定で、1派遣につき1回。近所への派遣と有力者への訪問には追加しない。
既に出発済みの派遣や旧リプレイには後付けしない。旧セーブでも新しく対象の派遣へ出発した分には適用する。

| 派遣先 | 選択 | 帰還報酬の増減 | 疲労 | ストレス |
| --- | --- | --- | --- | --- |
| 商店街の交流会 | 追加の仕事を引き受ける | +100 | +10 | +5 |
| 商店街の交流会 | 予定どおりの仕事を終える | 0 | 0 | 0 |
| 郊外への出張訪問 | 報酬の一部を使って休憩する | -50 | -10 | -10 |
| 郊外への出張訪問 | 予定どおり進む | 0 | 0 | 0 |

数値は暫定値。確率抽選・派遣の中断・期間変更・派遣中の家出は今回追加しない。

## 発生と回答

出発確認にイベントの予告を表示する。営業の閉店または休業で派遣1日目が終了すると発生し、回答まで次の営業・翌日・休業・追加派遣などを止める。
休業操作は従来どおり翌日の準備へ移るが、そこから先は回答が必要。

営業画面の案内欄に回答待ちを表示し、「確認する」から直接回答する。派遣画面でも対象を選び「出来事に回答…」で開ける。閉じても未回答のまま保持する。
回答後は同じ画面で確定した変化を確認できる。帰還後も派遣画面の「出来事の記録…」から閲覧できる。
複数の回答待ちや通常の帰還が同時にある場合は、それぞれ解決する。人気・有力者などの目標結果も別途確認する。
ゲームオーバー時は回答・報酬受取で営業を再開せず、記録の閲覧のみとする。

## 効果と精算

疲労・ストレスは回答時に一度だけ変更する。疲労は出勤ルールの上限、ストレスは0〜100に収める。経営ルール未導入ならストレス効果は適用しない。
派遣中の通常の休養回復・病気抽選・家出判定は追加しない。変化した状態を帰還後の管理に引き継ぐ。

報酬は回答時には入金せず、帰還を受け取るときに精算する。特性補正済みの基本報酬へイベントの増減を加え、最低0とする。
例：外出好きの郊外報酬562.5から休憩分50を引き、512.5を受け取る。帰還時の特性によるストレス増加は従来どおり別に適用する。
日次の派遣収入と所持金の検証にも、選択後の報酬を使う。

## 保存・再開

設定は `config/cafe_dispatch_encounters.json`。出発時に選択肢・効果・タイトルを固定し、派遣記録の任意項目 `encounter` に保存する。
未発生・回答待ち・回答済み、発生日・回答日・選択・実際の疲労とストレスの変化前後を記録する。詳細リプレイにも出発時の設定と回答操作を残す。
再開時に設定を再抽選・再読込しない。同じ回答の再送は何も変更せず、回答済みの内容を別の選択へ変更する操作は拒否する。保存失敗後の再試行でも効果を重複適用しない。
未回答のまま日程が進んだ記録、不正な選択・発生日・変化量などを拒否する。

## 検証

営業／休業からの発生、進行停止、選択4通り、疲労・ストレスの増減と下限、経営ルール未導入、特性との報酬・帰還ストレス併用、複数イベントと目標結果、旧派遣互換、保存失敗・再開・詳細リプレイ、二重適用防止、不正状態をテストする。
GUIでは案内からの回答、閉じても未解決の保持、効果表示、帰還受取と記録閲覧、最小サイズのボタン表示を確認する。
