# 日次収支と期間比較

更新日：2026-09-29 / 状態：初回実装済み

## 目的

売上と終了時の所持金だけでなく、その日にいくら入り、いくら使い、黒字・赤字のどちらだったかを確認できるようにする。増設、休業、派遣などの判断を複数日で比較する材料とする。

## 日次の集計

新規ゲームの確定した収入・支出から、次を導出する。

- 開始資金
- 収入合計
- 支出合計
- 純収支
- 終了資金

計算式は次のとおり。

`収入合計 = 接客売上 + 派遣収入`

`支出合計 = 店舗運営費 + 保護猫受け入れ費 + 増設費 + 待合スペース費 + 休養設備費 + 接客設備費 + 店舗イベント支出 + 子猫の引き渡し費`

`純収支 = 収入合計 - 支出合計`

`終了資金 = 開始資金 + 純収支`

開始時の資金補充は営業開始前の資金として扱い、その日の収入には数えない。人気の増減、アイテム入手、猫の加入・離脱は資金変化がある場合だけ上記の該当費用へ含める。

## 表示

- 閉店結果に開始資金、収入、支出、符号付きの純収支、終了資金を表示する。
- 「営業結果の比較」に同じ5項目の列を追加する。
- 比較画面の上部に、表示中の全日について収入・支出・純収支の合計を表示する。
- 休業日は収入0、店舗運営費などを支出として赤字額を表示する。
- 従来の売上、派遣収入、費用別の列は内訳として維持し、店舗イベント支出も独立した列で表示する。

## 保存と整合性

新しい明細履歴は増やさず、既存の日次結果に保存される確定済みの収入・費用から集計値を作る。読み込み時には次を確認する。

- 各日の収入・支出・純収支が内訳と一致する。
- 開始資金と純収支から終了資金を再計算できる。
- 翌日の開始資金が前日の終了資金と一致する。
- 全期間の終了資金が既存の会計検証と一致する。

運営費を持たない旧セーブには新しい集計項目を後付けせず、従来の結果表示を維持する。

## 初回確認範囲

通常営業、休業、増設、派遣、各種購入費、保存再開、日次間の連続性、破損した集計値、比較画面の累計表示を確認する。金額や収益性の調整は全体の流れが固まった後に行う。
