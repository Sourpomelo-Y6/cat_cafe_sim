# 有力者向け積極経営：希望に合う猫の確保と派遣待ち

更新日：2026-10-03。有力者向けの積極経営（`fast`）へ、希望に不足する特徴の保護猫受け入れと、一致する猫の休養待ちを追加した。安定経営（`clear`）は従来の判断を維持する。基礎営業、人気・好感度向けの判断、満足度・希望の巡回・育成・健康・派遣の数値、保存形式は変更しない。ゲーム・従来方針の基準コミットは `cae824e`。

## 判断と通常操作

積極経営は、未達の有力者が希望する特徴と、譲渡済みを除いた在籍猫の特徴を比較する。不足があり、飼育枠と予備資金に余裕があれば通常の保護猫候補を開く。掲載済み・未受け入れ・不足する特徴に合う候補のうち、費用の低い順・ID順で一匹ずつ受け入れる。受け入れ後も従来の運営予備資金（最低300・2日分の費用）を残す。通常の初期5匹には黒猫がいないため、最初の候補のリン（200）を受け入れる。

飼育枠不足、予備資金不足、掲載候補に一致がない場合は、受け入れを増やさず通常の派遣判断へ戻る。新しい候補の自動追加・飼育スペース拡張・ショップ購入は行わない。一人の有力者だけの旧セーブには不足特徴の条件がないため、受け入れを追加しない。

派遣候補は従来どおり加点の高い順・疲労の低い順・ID順。一致する猫が在店していて一時的に派遣できない場合、積極経営はその猫を休養し、不一致の低加点訪問を見送る。ほかの未達有力者へ派遣できるなら先に進める。健康・体力・疲労・ストレス・余剰猫などの通常条件を緩めない。

厳格型に必要な白猫の育成役は、引き続き店内で接客育成を優先し、この猫を待つことだけで気分型の巡回を止めない。必要な特徴の猫がいない、該当個体が譲渡済み・不在、必要な特性を満たさない場合も休養待ちの候補にしない。実行可能な候補から不一致の訪問で進むことがあるため、不一致を完全になくす方針ではない。

希望は帰還確認時に次へ巡回する。不一致のまま日数を待つだけでは希望が変わらない。出発時に固定した条件・加点と、通常の帰還受け取りを使う。全体で同時一件の訪問、相手の設定順、厳格型の育成・派遣役、予測疲労・ストレスとも60以下の出勤判断を維持する。設備・席の追加投資は行わない。

GUI・CLIは同じ自動プレイヤーを使う。判断一覧には候補確認・受け入れ・派遣待ち・希望一致の休養と理由を表示する。途中中止・保存再開後は最新の保存状態から同じ判断を行い、方針そのものは従来どおり開始時に選ぶ。
