# お客さんの信頼回復と永久離脱

更新日：2026-09-28 / 状態：初回実装済み

## 目的

累積不満による来店停止を何度も繰り返したお客さんに、信頼回復または永久離脱という長期的な結果を持たせる。
お詫び費用を支払う選択肢は設けず、今後の接客で信頼を回復できるかを扱う。

## 初回ルール

- 同じお客さんが2回目の来店停止になった翌日の準備中に、信頼回復イベントを表示する。
- 「信頼回復に取り組む」を選ぶと、停止期間終了後の接客結果を待つ。
- 信頼回復中の接客が「満足」なら回復成功。不満を25にして通常状態へ戻す。
- 接客が「普通」なら信頼回復中を維持し、次の来店で再び判定する。
- 接客が「不満」なら永久離脱する。
- 「対応しない」を選ぶと、その準備中に永久離脱する。
- 永久離脱時は店の人気を10下げ、以後の通常曜日・常連追加日・高難度客・増設客の予定から除外する。

信頼回復の選択や成功に資金は使わない。離脱した客の常連度、猫との親しみ、過去の接客評価、停止履歴は削除しない。
回復後に再び来店停止を起こした場合は、新しい信頼回復イベントが発生し得る。

## 画面と保存

回答待ちは営業画面の案内から「お客さんの信頼回復」を開いて選ぶ。回答前は営業・翌日進行・他の状態変更を止める。
営業ログには回答待ち、回復開始、回復成功、永久離脱と人気低下を表示する。顧客名簿には回答待ち・回復中・永久離脱と離脱日を残す。

設定、客ごとの状態、イベントの選択と結果を営業セーブへ保存する。再開や画面の開き直しでイベント、人気低下、回復処理を重複させない。
旧セーブには後付けせず、従来の一時停止と復帰を維持する。

## 確認

2回目の停止と翌日提示、回答待ちの進行防止、取り組む／対応しない、満足／普通／不満、人気低下、来店予定からの除外、履歴保持、再回復、保存再開、リプレイ、破損データ、旧セーブ互換を確認する。
