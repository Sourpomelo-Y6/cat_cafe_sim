# 営業の割り当てと自動交流

更新日：2026-09-13

通常営業では、プレイヤーはお客への担当猫の割り当てと営業状況の確認を行う。
割り当て後の交流コマンドはシステムが選び、終了時の会計・親しみ保存まで自動で進める。
これまでのコマンドボタン付き営業画面は検証専用へ分離した。

## 通常の営業画面

```bash
python3 -m cat_cafe_sim.cafe_interaction gui
```

- 手動割り当て：「営業を開始・再開」で来客を待つ。待機客が現れたら割り当て待ちで一時停止する。お客と担当猫を確認し「担当猫を割り当てる」を押すと、交流の自動進行を開始する。
- 自動割り当て：「自動割り当て」を選び「営業を開始・再開」を押す。空席と交流可能な猫があれば、待機順にお客へ割り当てる。
- 「一時停止」で営業時計と交流を止め、「営業を開始・再開」で続きから進める。手動・自動の割り当て設定を変更しても、現在交流中の組み合わせは変えない。

現在の営業coreは1匹・1席。担当猫の候補は営業中のcat-1で、名前と個性は保存データから引き継ぐ。
複数の登録猫を営業へ参加させて選ぶ機能はまだ含まない。猫が体力切れ・不健康なら自動で割り当てず、来客・待機期限・閉店の処理を進める。

通常画面には交流コマンド・動作変更先・切り上げ会計ボタンを表示しない。
約700ミリ秒ごとに最大1営業tickを進める。描画や保存で遅れた分のtickをまとめて消化しない。
手動割り当て待ち、一時停止中、ログ保存ダイアログ、アプリ終了確認中には自動進行を止める。
ログ保存や終了確認のキャンセル後は一時停止のままなので、必要なら営業を再開する。

関係保存の失敗時も自動進行を止める。「結果保存を再試行」が成功してから、プレイヤーの再開操作で続ける。
閉店時はタイマーを解除する。同時に複数のタイマーを登録せず、再開操作で二重に進行しない。

## 自動コマンドの暫定規則

`AutomaticInteractionPolicy`（automatic-interaction-v1）が公開された反応・体力と使用可能コマンドから選ぶ。

1. 心をつかむが使用可能なら選択する。100到達の強制予約にも対応する。
2. 体力20以下なら停止して回復を試みる。
3. 前回がそっぽを向く・戸惑う反応なら、次の種類へ切り替える。
4. それ以外は通常の働きかけ（direct）を選ぶ。

切り替え順は、ねこじゃらし→ボール→ぬいぐるみ→トンネル→なでる→ブラッシング→声かけ→見守る→ねこじゃらし。
お客の働きかけをこの規則で選び、猫の反応・心を開くは既存の版4処理に任せる。
猫の非公開の好みを直接参照せず、好みが反応へ表れることで次の選択が変わる。学習済み方策や収益を最適化した方策ではない。
任意終了は自動選択せず、交流時間終了・体力切れ・閉店で会計する。低体力からの特別行動達成を目標にしない。

## 検証用手動操作とCLI

```bash
# コマンドボタンを表示する検証用画面
python3 -m cat_cafe_sim.cafe_interaction gui --manual
# 通常のCLIは自動割り当て・自動交流で閉店まで進む
python3 -m cat_cafe_sim.cafe_interaction run
# 手動の検証操作を指定する場合
python3 -m cat_cafe_sim.cafe_interaction run --operations wait start:guest-1 direct finish
python3 -m cat_cafe_sim.cafe_interaction replay reports/cafe_interaction.json
```

保存先・会計・体力・親しみの扱いは[営業接続仕様](HumanToCatCafeIntegration.md)を維持する。
自動選択後の具体的な行動を従来どおりログに記録し、再生は方策を再実行せず記録済み行動を使う。既存の手動営業交流ログも同じ形式で扱う。
営業状態の永続セーブは未実装で、所持金・時計・体力は起動中だけ保持する。

## 検証結果

通常テスト198件と画面専用15件、計213件が成功。
手動割り当て待ちで時計が止まること、割り当て後の自動行動、待機順の自動割り当て、閉店までの進行、特別行動・低体力・反応による選択、保存失敗と二重会計防止を確認した。
GUIではコマンド非表示、一時停止・再開、単一タイマー、保存再試行後の明示再開、860×600でのログ・操作領域を確認した。
既定設定・新規保存先の自動CLIは40tickで閉店し、会計440（特別行動50を含む）、残り体力19。再生結果も一致した。これは動作確認でありバランス調整の達成基準ではない。
