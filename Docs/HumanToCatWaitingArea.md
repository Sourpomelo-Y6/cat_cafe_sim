# 待合スペースの施設強化

更新日：2026-09-29 / 状態：初回実装済み

## 目的

席数と来客数が増えた後の混雑に、猫の配置だけでなく施設投資でも対応できるようにする。待機列満員と待ち時間切れを減らす代わりに、購入費と毎日の固定費を負担する選択とする。

## 解放・購入

- 新規の人気目標ゲームで第1段階を達成すると解放する。
- 営業準備中に「準備・お店」→「待合スペースを強化する…」から購入する。
- 購入費は暫定800。支払い後に資金が残る場合だけ購入できる。
- 一度だけ購入でき、売却・返金はできない。
- 購入当日の営業から効果を適用する。
- 人気低下後も購入済みの効果を維持する。

## 効果と維持費

| 項目 | 強化前 | 強化後 |
| --- | ---: | ---: |
| 待機人数の上限 | 4人 | 5人 |
| 待機できる時間 | 8tick | 10tick |
| 日次運営費への追加 | 0 | 10 |

上限を超えて来店した客は従来どおり満員で退店する。待機時間を使い切った客も従来どおり退店し、どちらも累積不満へ接続する。閉店時刻を延長する効果はない。

購入日の支出には購入費800を計上し、その日の閉店または休業から運営費10も追加する。休業日にも維持費は発生する。

## 表示・結果

- 強化画面に現在と強化後の待機上限、待機猶予、購入費、維持費、購入後資金を表示する。
- 営業ログに購入費と効果を表示する。
- 閉店結果に満員退店数と待ち時間切れ数を表示する。
- 複数日の比較画面に「満員帰り」「待切れ」「待合費用」を表示する。
- 待合スペース購入費と維持費を日次収支の支出に含める。

## 保存・互換性

購入日と固定したルールを営業セーブへ保存し、保存再開やリプレイで購入・課金・効果を重複させない。購入条件、購入費、日次結果、所持金との整合性を読み込み時に検証する。

旧セーブには待合スペースを後付けせず、従来の待機上限と待機時間を維持する。数値の調整や複数段階の強化は、全体の流れを確認した後の候補とする。
