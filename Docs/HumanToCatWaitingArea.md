# 待合スペースの施設強化

更新日：2026-09-30 / 状態：購入と2段階目の強化を実装済み

## 目的

席数と来客数が増えた後の混雑に、猫の配置だけでなく施設投資でも対応できるようにする。待機列満員と待ち時間切れを減らす代わりに、購入費と毎日の固定費を負担する選択とする。

## 解放・購入

- 新規の人気目標ゲームで第1段階を達成すると解放する。
- 営業準備中に「準備・お店」→「待合スペースを強化する…」から購入する。
- 購入費は暫定800。支払い後に資金が残る場合だけ購入できる。
- 一度だけ購入でき、売却・返金はできない。
- 購入当日の営業から効果を適用する。
- 人気低下後も購入済みの効果を維持する。

## 2段階目の強化

待合スペース購入済み・人気第2段階達成後の営業準備中に、同じ画面の「2段階目へ強化する」から一度だけ強化できます。暫定費用1,200で、支払い後に資金が残る場合のみ可能。所持金1,200以下では強化できません。設定は [cafe_waiting_area_upgrade.json](../config/cafe_waiting_area_upgrade.json)。

確認画面で待機上限・猶予・維持費の変更前後、費用、支払後の資金を表示します。キャンセルでは変更しません。当日の営業から有効で、維持費も当日の閉店・休業から合計20へ変更します。営業中・閉店後・結果保存待ち・プレイヤー交流中・イベントや成長などの回答待ち・ゲームオーバー中は強化できません。

購入済みの旧セーブでも人気第2段階達成後なら明示的に強化できます。読み込みだけでは変更せず、元の購入記録と設定・過去の維持費を保ちます。待合ルールのない旧ゲームへ施設を後付けしません。設定を変更した旧設備についても、強化後の待機上限・猶予が現在より増える場合だけ強化します。

## 効果と維持費

| 項目 | 購入前 | 購入後 | 2段階目 |
| --- | ---: | ---: | ---: |
| 待機人数の上限 | 4人 | 5人 | 6人 |
| 待機できる時間 | 8tick | 10tick | 12tick |
| 日次運営費への追加 | 0 | 10 | 20 |

上限を超えて来店した客は従来どおり満員で退店する。待機時間を使い切った客も従来どおり退店し、どちらも累積不満へ接続する。閉店時刻を延長する効果はない。

購入日の支出には購入費800を計上し、その日の閉店または休業から運営費10も追加する。休業日にも維持費は発生する。2段階目の購入費1,200は強化日の待合費用へ加算し、同じ日に初回購入と強化を行う場合は合計2,000。維持費は初回10と強化後20を足さず、その日の日付に対応する合計値を使用する。

## 表示・結果

- 強化画面に現在と強化後の待機上限、待機猶予、購入費、維持費、購入後資金を表示する。
- 営業ログに購入費と効果を表示する。
- 閉店結果に満員退店数と待ち時間切れ数を表示する。
- 複数日の比較画面に「満員帰り」「待切れ」「待合費用」を表示する。
- 待合スペース購入費と維持費を日次収支の支出に含める。

## 保存・互換性

購入日と固定したルールを営業セーブへ保存し、保存再開やリプレイで購入・課金・効果を重複させない。購入条件、購入費、日次結果、所持金との整合性を読み込み時に検証する。

待合ルールのない旧セーブには設備を後付けせず、従来の待機上限と待機時間を維持する。購入済み記録に任意の `upgrade`（強化日、固定した費用・上限と猶予の合計追加量・維持費）を追加し、設定変更後も保存済みの値を使用する。詳細リプレイの `upgrade_waiting_area` 操作で強化と課金を再現する。復元時は解放条件・日付、日次の待合費用、各日の維持費、所持金を照合する。保存失敗時も起動中の強化結果を保持し、再購入せず保存を再試行する。

さらに先の段階や細かな数値調整は後続候補とする。
