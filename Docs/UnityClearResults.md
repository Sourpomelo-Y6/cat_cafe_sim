# Unity クリア記録

メニューの「クリア記録：達成時の成果を見返す」から、達成済み目標を選んで記録を確認します。人気目標は最終段階のみ、有力者の満足度・猫との好感度はそれぞれの達成結果を表示します。途中段階・期限内未達はクリア記録に含めません。

## 表示内容

達成日、目標の達成値、所持金、店の人気、在籍猫数、累計接客売上を表示します。Python既存の `clear_results` の固定値を使い、継続営業後の現在値では補いません。旧セーブに詳細記録がない場合はPython版と同じ既存の達成情報だけを表示し、資金・人気・在籍猫数・売上は「記録なし」とします。

継続営業・保存再開後も再閲覧できます。達成済み目標が複数ある場合は選択欄で切り替えます。新規ゲームや別ゲーム読込では画面を閉じ、古いゲームの表示を引き継ぎません。記録なし・未接続・ゲームオーバーも区別し、未接続時は最後に取得した記録であることを表示します。

閲覧は読み取り専用です。新しい記録の生成・課金・報酬・乱数・ゲーム設定の変更を行いません。継続操作は既存の結果画面、別ゲームの開始は既存のタイトル画面を使います。

## 検証

- Pythonの既存クリア記録テストと状態API回帰、および追加したUnity連携3件を確認。
- 最終段階だけの表示、継続後の固定値、複数目標・旧セーブ・未達の表示。
- HTTPで継続・休業・保存・読込・新規開始を確認。読み取りによる状態変更と元ファイルの書換えがないことを確認。
- Unityでメニュー15項目の配置、空の記録・3目標切替・未接続・ゲームオーバー・別ゲーム読込・閲覧中に操作要求を送らないことを確認。
- Unity Playモードの実ボタンでメニューから閲覧、継続、保存、タイトルから再開、達成記録の再表示を確認。
- メニュー、記録画面、保存再開後の実画面を撮影して表示を確認。
