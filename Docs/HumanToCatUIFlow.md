## 常設する情報と操作

- 上部に営業日・段階、資金、席数、猫数、導入済みなら人気を表示。
- 営業の開始・停止、閉店後の翌日操作、準備中の休業を上部に配置。
- 保存・読み込み・営業履歴・新規ゲームの入口を常設。
- 確認待ちの案内と、該当画面を開く「確認する」ボタンを表示。
- 下部の営業ログはタブを変えても表示する。

初期サイズは1100×800、最小サイズは860×660。猫一覧は縦横にスクロールできる。席の詳細は縦スクロールで設備効果と交流状況を確認できる。ログ書き出しは「ファイル」メニューから行う。

## タブと操作

| タブ | 内容 |
| --- | --- |
| 営業 | お客さん・担当猫・席の選択、自動割り当て、猫の状態一覧、猫の詳細と交流、お客との相性、各席の交流状況 |
| 準備・お店 | お客さんの名簿・来店予定、出勤・休養、所持品・猫のケア、保護猫の受け入れ、店先に通う猫との交流・加入、派遣・帰還、席の増設、休養スペース購入、席の接客設備 |
| 結果・記録 | 当日の接客結果、人気目標、有力者目標、猫との好感度目標、譲渡の申し出・設定、家出・帰還・経営状態 |

受け入れや目標確認などはメイン画面から直接開く。通常営業の派遣画面は派遣と帰還確認に用途を絞る。

## 10日間おまかせ

「営業」タブの猫の詳細・相性ボタンと並ぶ「10日間おまかせ…」から専用画面を開く。人気目標に挑戦中のゲームで「基礎営業」「クリアを目指す」の方針を選び、経過日数を見ながら最大10日を自動で進められる。「判断一覧」タブで日・対象・出勤／休養／購入／予約の判断・理由・実行結果を確認でき、行を選ぶと理由の全文を読める。「操作ログ」タブで従来の日本語ログも確認できる。判断一覧は同日・同対象を最新の判断に更新し、新たなおまかせ開始時にリセットする。各人気段階の達成・期限切れ・ゲームオーバーでも止まる。中止・画面を閉じる際は操作の境界で止まり、終了時に資金・人気・猫の状態変化を表示する。現在の保存先があれば営業セーブへ保存し、操作ログは別途書き出せる。結果確認や次段階への挑戦は通常の画面で行う。[詳細仕様](HumanToCatAutoPlayPlan.md#gui10日間おまかせ)。

## 進行と一時停止

営業タブ以外へ移動したとき、または詳細画面を開いたときは自動進行を停止する。営業タブへ戻るだけでは再開せず、開始・再開ボタンを押して進める。
タブを切り替えるだけではゲーム状態を変更しない。接客コマンドは引き続き自動で選ばれる。

保存待ち、家出からの帰還、譲渡、派遣からの帰還、目標結果などは案内欄から対応する。複数ある場合は順に案内する。プレイヤー交流の途中状態も猫の詳細へ案内する。
各操作の実行条件・料金・回復量・保存形式は従来の仕様を維持する。

GUIテストでタブ切り替え時の状態保持と停止、ログ表示領域、直接の画面遷移、既存操作を確認する。仮想ディスプレイ上で3タブと最小サイズの見た目も確認する。

お客さんの名簿では、今日・翌日の来店予定・来店曜日・好み・来店回数と猫別の親しみを閲覧できる。[名簿の仕様](HumanToCatCustomers.md)を参照。

## 派遣中の選択イベント

商店街・郊外への新規出発分に、1日目終了時の選択イベントを追加した。回答待ちは営業画面の案内欄から直接開ける。選択後の報酬・疲労・ストレス、保存互換は[派遣中の選択イベント](HumanToCatDispatchEncounters.md)を参照。既に出発済みの派遣には後付けしない。

## 所持品と猫のケア

「準備・お店」の出勤設定の横に「所持品・ケア…」を配置する。所持数・効果と猫の活動・ストレスを確認し、準備中に1個ずつ使用する。画面内の「使用履歴」で結果を再確認できる。[アイテム仕様](HumanToCatItems.md)を参照。

2026-09-30追記：「準備・お店」の猫の準備に「常連からの猫紹介…」を追加。紹介待ちは案内の「確認する」からも開き、候補・個性・特徴・特性・費用・飼育枠・受け入れ後の資金と回答履歴を確認できる。[仕様](HumanToCatRegularIntroduction.md)。

「準備・お店」の猫の準備に「店先に通う猫…」を追加。情報・交流回数・費用・飼育枠・日ごとの履歴を表示し、交流する／今日は見送る／迎えるを確認して選ぶ。任意操作なので営業開始を止めず、進捗を保持して後日迎えられる。画面内から飼育スペースを拡張できる。[仕様](HumanToCatVisitingCat.md)。
