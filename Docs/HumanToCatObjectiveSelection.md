# 新規ゲーム開始時の目標選択

2026-09-27追記：達成後は[共通クリア結果画面](HumanToCatClearResults.md)で成果を確認し、継続か別の新規ゲームを選べる。新規ゲームでは達成時点の集計を固定して保存する。

新しく店を始める際に、今回の目標を選ぶ。既定は「人気3段階」。初期猫・席・資金などは共通で、数値の細かな調整や難易度選択は後続とする。

| 選択肢 | 初回の達成条件 | 期限 |
| --- | --- | --- |
| 人気3段階 | 人気150 → 225 → 300。段階ごとに次の挑戦か自由営業を選ぶ | 各段階の開始から10日間 |
| 有力者の満足度 | 有力者への派遣・帰還報酬の受取で満足度100 | なし |
| 猫6匹との好感度 | プレイヤー好感度80以上の在籍猫が同時に6匹 | なし |
| 自由営業 | 開始時のクリア目標なし | なし |

## 操作

「新しく始める」または営業画面の「新規ゲーム…」から開く。
「挑戦する目標」タブで4種類から選び、達成条件・期限を確認する。「初期条件」タブで猫・資金・席・経営ルールを確認し、「この条件で新しく始める」で開始する。
選択の変更・画面の閲覧・キャンセルではゲームやファイルを作らない。新規作成に失敗しても既存のゲームは維持し、同じ選択で再試行できる。

選んだ目標は1日目の準備から有効。営業タブの猫一覧の上と「結果・記録」に、その目標の進捗を表示する。目標達成時の結果確認・継続営業は既存の各目標画面で行う。
有力者を選んだ場合は、最初から有力者への派遣先が使える。好感度目標では初期5匹に加え、保護猫の受け入れなどで猫を迎えて6匹を目指す。

今回の選択は「開始時に有効化する目標と主に表示する進捗」を決める。既存の有力者・好感度目標の任意導入機能は維持し、後から追加しても開始時の選択表示は変更しない。
自由営業・好感度モードでは、準備中に[人気3段階への挑戦](HumanToCatPopularityChallenge.md)を任意で開始できる。開始時の選択表示は維持し、現在の進捗には人気挑戦を表示する。好感度モードでは元の好感度目標も併記し、両方の結果を独立して確認する。有力者モードでは途中からの人気挑戦は設けず、人気目標画面は「人気の増減ルール…」として閲覧できる。

## 共通の経営ルール

どの選択でも接客による人気の増加と上限300、家出による人気の減少を有効にする。人気挑戦開始前の自由営業・有力者・好感度では人気の期限付きクリア／未達を判定せず、10日目で進行を止めない。
資金0以下または人気0のゲームオーバーは全選択で有効。自由営業もこの終了条件を持つ。
開始時の資金・猫・席、加入依頼、派遣・設備などの条件は従来どおり。達成による自動的な新規ゲームへの移行は行わない。

## 保存と旧セーブ

任意項目 `objective` に開始時の選択を保存し、各目標の設定・進捗・結果は既存の保存形式を使う。設定ファイルが変わっても、再開時に別の目標を開始しない。
人気以外の選択の開始時は、既存の人気獲得記録に `tracking_only: true` を付けて人気計算のみを行う。期限判定・人気目標の確認待ち・架空の達成結果は追加しない。
旧セーブに選択情報がなければ、従来の表示・目標設定で再開する。既存の単段階・3段階・複数目標を新しい選択へ自動変換しない。
新しい選択も詳細リプレイに記録する。復元時は選択と有効な目標・人気計算が整合することを確認する。

## 検証

4種類の初期化と保存再開、旧セーブ互換、自由営業の人気増加と期限なし、有力者・好感度の達成と継続、ゲームオーバー、作成失敗と再試行、不正な選択、詳細リプレイをテストする。
GUIでは選択内容・説明、選択中のファイル非変更、再開後の進捗、500×460の開始画面と860×660の営業画面で操作ボタン・ログが見えることを確認する。

自由営業・好感度モードからの明示的な人気挑戦開始後は、人気集計の過去履歴を維持しつつ、別に保存する開始日から期限を数える。詳細は[途中開始の仕様](HumanToCatPopularityChallenge.md)を参照。
