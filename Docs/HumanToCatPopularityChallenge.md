# 自由営業・好感度モードから人気3段階へ挑戦

更新日：2026-09-30 / 状態：実装済み

「自由営業」または「猫6匹との好感度」で開始したゲームは、準備中に「結果・記録」→「人気3段階へ挑戦…」から任意で挑戦を開始できる。目標画面で開始を確認し、キャンセルや閲覧だけでは状態を変更しない。有力者モードは対象外。

## 期限と引き継ぐ状態

人気150→225→300を各10日間で目指す。最初は挑戦開始日を含む10日間で、後続段階はその段階の開始日から数える。人気挑戦前の日数で期限を減らさない。休業も挑戦中は日数に含める。既に目標以上の人気があっても、開始操作ではクリアせず、その日の閉店・休業日の精算時に判定する。

猫・資金・人気・席・設備・成長・関係・派遣・過去の営業結果を維持する。既存の人気増加量と上限も変えず、挑戦前の獲得履歴を残す。開始時のモードを維持する。自由営業では人気挑戦の進捗、好感度モードでは好感度と人気の両方の進捗を営業画面と「結果・記録」に表示する。取消・期限リセット・未達後の再挑戦は設けない。

営業中・閉店後・ゲームオーバー中、未保存の接客結果、進行中のプレイヤー交流、帰還・イベント・成長・目標結果などの確認待ちがあると開始できない。開始済みのゲームでも二重に開始できない。

## 好感度目標との併用

好感度目標の条件・開始日・進捗・達成猫・成果記録を維持し、人気目標とは独立して判定する。好感度達成前でも、達成後に結果を確認して継続した後でも人気挑戦を開始できる。好感度の結果確認待ちでは開始できない。

好感度達成時は好感度画面で、人気達成・期限切れ時は人気画面で結果を確認する。確認済みの側の結果をもう一方の操作で変更しない。好感度の結果確認待ちでは人気の次段階に進めない。人気が期限内未達でも、結果を確認して営業を続ければ好感度目標を達成できる。両方の最終達成記録を共通クリア結果に保存する。

資金・人気のゲームオーバーは両目標に優先する。好感度目標に期限を追加せず、人気挑戦の期限も好感度の達成でリセットしない。

## 客層と増設

開始時に追加客の条件を固定し、人気モードと同じ達成段階で解放する。第1段階では白猫好き・静かな交流客・遊び客・触れ合い客、第2段階では特別予約、最終段階ではVIP。来店は達成翌日以降で、各客の曜日・設備・通常行動・特別行動の条件を維持する。

既存の増設条件も使い、第1段階で4席、第2段階で5席、最終段階後の継続営業で6席を購入できる。開始時の自動増設・費用徴収・追加客の来店はない。

## 保存と互換性

人気集計の `started_day` と `days` は維持する。挑戦開始日を任意項目 `goal.challenge_started_day`、現在段階の開始日を `stage_started_day` に保存し、期限の計算を人気集計の開始日から分離する。開始操作には目標と追加客の設定を保存し、詳細リプレイでも固定済みの設定を使う。

旧セーブ・旧ログは自動変換しない。開始時のモードが「自由営業」または「猫6匹との好感度」で、人気集計と必要な経営・曜日・好みの設定がある旧ゲームでは、明示的な新しい開始操作から利用できる。目標選択のない旧ゲームや他モードの目標を推測して置き換えない。開始後の保存再開、接客中の保存、保存失敗後の再試行で開始・報酬を重複させない。

開始日と段階履歴、人気の獲得・上限、モード、追加客の設定が矛盾する保存データは拒否する。
