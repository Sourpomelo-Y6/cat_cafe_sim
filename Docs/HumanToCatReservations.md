# 人気第2段階で解放する特別予約

更新日：2026-09-29 / 状態：初回実装済み

## 目的

翌日の公開条件を見て、猫の出勤・休養・派遣と席設備を準備する判断を増やす。通常客より条件が厳しい代わりに、追加料金と人気を多く得られる客として扱う。

## 解放と依頼

新規ゲームの人気目標第2段階を達成すると解放する。第2段階の結果を確認して翌日の準備へ進んだ時、一度だけ翌日分の予約依頼を提示する。
「予約を受け入れる」「見送る」を選ぶ。見送りによる資金・人気・不満のペナルティはない。

受け入れた場合は翌日の進行0で予約客が来店する。予約日は休業できない。依頼を受け入れる前の当日は通常どおり営業・休業できる。
旧セーブ、人気以外の目標モード、期限なしの人気集計には後付けしない。

## 初回の予約条件と報酬

予約客は「長毛猫との時間を望む予約客」。来店前から次の条件を顧客名簿と依頼画面に表示する。

- 長毛の特徴を持つ猫を担当にする。
- 接客中に「心を開く」を1回以上発動する。
- 両方を満たすと追加料金200、通常の満足接客による人気に加えて人気＋5。

達成・未達は[1回ごとの接客評価](HumanToCatCustomerSatisfaction.md)にも加点・減点する。普通・不満、待機失敗、累積不満、来店停止、信頼回復は既存のお客さんと同じ仕組みを使う。
予約日に来店しても接客されなかった場合は未接客として記録し、条件報酬は与えない。

## 画面・保存

回答待ちは営業画面の案内から予約画面を開く。顧客名簿には解放前、回答待ち、受け入れ、見送り、条件達成・未達を表示し、長毛・心を開く回数・報酬を確認できる。
営業ログには解放、依頼、回答、条件結果、未接客を表示する。

設定、依頼日、来店日、回答、接客結果を営業セーブへ保存する。再開や画面の再表示で依頼・来店・報酬・人気を重複させない。日次の来店予定、会計、人気、接客成果と照合する。

## 確認

第2段階前後、受け入れ・見送り、翌日来店、予約日の休業禁止、条件達成・未達、未接客、追加料金、人気、名簿、保存再開、詳細リプレイ、破損データ、旧セーブ互換を確認する。
