# 曜日別の来店と今日・翌日の予定

2026-09-28追記：[累積不満](HumanToCatCustomerDiscontent.md)が100に達した客は翌日から7日間、通常曜日・常連追加日・高難度客・増設客の予定から除外する。休止中の予定は繰り越さず、不満50で復帰した後の次の対象日に来店する。

2026-09-28追記：[常連](HumanToCatCustomerLoyalty.md)になった通常客は、本来来ない固定曜日に週1回追加来店する。常連化の翌日以降から有効で、休業日は来店せず次週の同じ曜日を待つ。元の予定と重なる場合は1日1回来店を維持する。

2026-09-28追記：[4席への増設](HumanToCatExpansion.md)の購入翌日から、曜日に関係なく通常客1人を開店時に追加する。既存客と高難度客の予定は変更せず、休業日は追加客も来店しない。

2026-09-28追記：[高難度客](HumanToCatAdvancedCustomers.md)導入済みゲームでは、人気第1段階達成の翌日から営業日に1名を追加する。この客は曜日に関係なく開店時に来店し、通常客の曜日・時刻を変更しない。来店IDは同じ日次実績へ記録する。休業日は追加客も来店しない。

## 初回仕様

新規ゲームに固定曜日の来店を導入する。1日目は月曜日で、翌日へ進む・休業するたびに曜日も1日進む。日曜日の次は月曜日。
現実のカレンダーとは連動しない。旧セーブには読み込み時に導入せず、従来の毎日同じ予定を維持する。

初回の暫定パターンは次の2種類。お客さんIDの番号順に交互に割り当てる。

| お客さん | 来店曜日 |
| --- | --- |
| guest-1、guest-3、guest-5… | 月・水・金・日 |
| guest-2、guest-4、guest-6… | 火・木・土・日 |

来店する日の進行時点は既存の `arrival_ticks` を使う。来ないお客さんの枠を詰めず、IDも振り直さない。名前・好み・猫別の親しみを同じIDで引き継ぐ。
曜日のない日はそのお客さんを生成しない。設定次第で来店者が0人の日も営業・閉店・翌日へ進める。
来店頻度・人数の細かな調整は後回しとし、確率による来店変動・常連度・曜日の編集は初回に含めない。

## 画面

- 通常営業の上部に「1日目（月）」のように曜日を表示する。旧セーブは従来の日数表示。
- 「準備・お店」→「お客さんの名簿・来店予定…」で今日／翌日を切り替える。
- 予定がない日は「—」「予定なし」と表示する。実績・親しみは切り替えでも現在の確定値のまま。
- 選択したお客さんの来店曜日を、猫別の親しみ一覧の上に表示する。
- 予定の閲覧だけでは時間や営業状態を変更しない。

予定はその日に営業した場合のもの。休業すれば来店せず、次の日の曜日・予定へ進む。未解決イベントや目標結果などで進行できない場合も、翌日の予定は参照できる。

## 保存・実績

`config/cafe_weekdays.json` に開始曜日と曜日パターンを定義する。新規開始時に検証して営業状態の任意項目 `weekdays` へ固定し、保存済みゲームの再開では設定ファイルを読み直さない。

曜日導入済みの営業では、日次結果に実際の来店ID一覧 `customer_visits` を追加する。日ごとに来るお客さんが異なるため、全体の来店人数だけから個人の回数を推測しない。
接客できなかった来店も含み、休業日の一覧は空。名簿は過去の来店ID一覧と当日の来店を集計し、閉店・翌日・保存再開で二重計上しない。
詳細な接客行動履歴は追加せず、来店IDのみを日次で保持する。

旧セーブは `weekdays` と `customer_visits` を追加せず、従来の固定順序による集計を維持する。新形式の設定・来店実績・再来店者一覧が矛盾する保存は拒否する。
初回設定操作 `initialize_weekdays` と曜日付き営業の詳細リプレイにも対応する。

## 検証

1席・複数席、月火の入れ替わりと日月の循環、ID維持、今日・翌日予告と実来店の一致、来店0人、同時来店・列満杯、休業、再来店判定、保存再開と設定固定、詳細リプレイ、不正設定・実績の拒否を確認する。
GUIでは曜日表示、閲覧切り替えで状態が変わらないこと、選択の保持、最小サイズの表示を確認する。

## 設備条件を持つお客さんの曜日

[遊び好きのお客さん](HumanToCatPlayCustomer.md)を導入した新規ゲームでは、人気第1段階達成後の翌日以降、遊び客は火・木・土、[静かな交流客](HumanToCatQuietCustomer.md)は月・水・金に来店する。日曜日は両客の定期来店がない。曜日設定はゲーム開始時に保存し、旧静かな交流客の毎日の来店は変更しない。

[触れ合い好きのお客さん](HumanToCatContactCustomer.md)を導入した新規の人気モードでは、第1段階達成の翌日以降の日曜日に1名来店する。お手入れブラシの席で通常の触れ合い3回以上を行うと追加料金160・人気3。既存の遊び客・静かな交流客の来店設定と旧セーブは維持する。
