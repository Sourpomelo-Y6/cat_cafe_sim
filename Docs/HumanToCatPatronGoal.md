# 有力者への派遣と満足度目標

更新日：2026-09-22 / 状態：有力者1人の初回実装済み

[実装予定のクリア案（2）](HumanToCatPlannedFeatures.md)を派遣に接続する。
人気目標とは独立して達成できる。両方の達成をクリアの必須条件にはしない。
細かな数値調整は後回しにする。

## 開始と操作

1. 経営ルールが有効な営業準備中に「派遣・イベント…」→「有力者目標・結果…」を開く。
2. 条件を確認して「目標を開始」。確認をキャンセルした場合は変更しない。
3. 派遣先一覧に追加される「地域の有力者への訪問」を選び、猫を派遣する。
4. 帰還・報酬を受け取ると満足度が増える。目標画面と派遣画面のボタンで進捗を確認する。
5. 満足度が目標値に届くとクリア。結果画面から継続営業を選択する。

新規ゲームでも自動では開始しない。旧セーブの読み込みでも導入せず、どちらも準備中に一度だけ明示開始する。
開始後の取り消し・リセットはない。接客成果の保存待ち、イベント待ち、プレイヤー交流中、目標結果待ち、ゲームオーバー時は開始不可。

## 暫定条件

設定は [cafe_patron.json](../config/cafe_patron.json)。

| 項目 | 初回の値 |
|---|---|
| 対象 | 地域の有力者1人 |
| クリア目標 | 満足度100 |
| 帰還1回の満足度 | ＋25 |
| 期限 | なし |
| 派遣期間 | 2日 |
| 基本資金報酬 | 200（派遣全体） |
| 猫の条件 | 在店・健康・担当可能、疲労40以下、必要特性なし |

既存の派遣と同じく、店内の席数を超える担当可能な猫が必要。同じ猫の同日再派遣は不可。
複数の猫を同じ有力者へ同時に派遣でき、各帰還を1回と数える。初回は人数制限や同時派遣による減衰を設けない。
通常営業の閉店・休業で日数が進む。派遣中には在店の休養回復を適用しない。
外出好きは資金報酬250・帰還時ストレス＋10となるが、満足度は特性によって増減しない。
通常の3種類の派遣先では満足度は増えない。

## 確定時点・終了と継続

- 出発や帰還待ちの時点では満足度を加算せず、帰還を受け取った時点で資金とともに一度だけ確定する。
- 満足度は目標値で上限にする。100到達後の帰還でも資金は得られるが、満足度は100のまま。
- 目標到達日を保存する。継続営業後も達成日を書き換えたり、再びクリア確認を要求したりしない。
- クリア確認待ちは営業・翌日・休業・新規派遣などの進行を止める。残っている帰還・譲渡等の確認は可能。
- 未処理の帰還・譲渡等がある場合、先にすべて処理してから「結果を確認して営業を続ける」を押す。
- 人気目標も結果確認待ちなら、両方の結果を個別に確認する。確認順序はどちらでもよい。
- ゲームオーバーを優先する。終了後は帰還受取や継続操作をできず、報酬・満足度も加算しない。
- クリア後に継続していても、資金・人気によるゲームオーバーは引き続き適用する。

## 表示・履歴・保存

派遣の既存履歴に行き先、残日数、帰還待ち、受取済み、資金報酬を残す。
営業ログには満足度の増分・合計・クリア・継続を表示する。
満足度・クリア状態と達成日は目標画面で再確認できる。

営業セーブ形式2・チェックポイント1に任意の `patron` を追加する。
目標の開始日、開始時の設定、満足度、状態、達成日、継続確認を保持する。
有力者の派遣先は開始時の設定を使い続け、途中で設定ファイルを編集しても報酬・条件・目標値を変えない。
復元時には有力者への派遣・受取履歴から満足度と達成日を照合する。
目標設定なしの有力者派遣、開始前の派遣、設定の異なる派遣、不正な満足度・結果は拒否する。
リプレイ4に目標開始と継続操作を追加。満足度は既存の帰還受取操作から再現する。
