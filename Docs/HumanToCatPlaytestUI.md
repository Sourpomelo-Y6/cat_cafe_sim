# 人と猫の交流：試遊画面

更新日：2026-09-07

Tkinterで、[単独交流モード](HumanToCatInteractionImplementation.md)をボタン操作できる画面を追加した。
行動効果・猫の反応・終了判定は既存の`HumanCatInteraction`を呼び出す。暫定値や学習モデルは変更していない。

## 起動

```bash
python3 -m cat_cafe_sim.human_cat_gui
# 別のルール設定を使用する場合
python3 -m cat_cafe_sim.human_cat_gui --config config/human_cat_interaction.json
```

PythonのTkinterとデスクトップ表示環境が必要。Gymnasium・NumPyは不要。
Tkinter未導入や画面に接続できない場合は、起動時に理由を表示して終了する。

## 操作

- 6つの行動ボタンから選択する。1クリックで1ターン進み、猫の反応が日本語で表示される。
- 関心・体力は数値とバー、残り時間と現在種類（遊び／なでる）は文字で確認する。
- 下部の履歴には、人の動作・猫の反応・関心と増分・残り体力を表示する。
- なでる間は「激しく動かす」「フェイント」を無効にする。終了後は全行動を無効にし、終了理由を表示する。
- 遊び／なでるの好み（各0〜2）と開始体力を編集し、「この条件で再開始」で適用する。
  編集だけでは進行中の交流に影響しない。不正な入力ではエラーを表示して現在の交流を保持する。
- 再開始すると関心・時間・履歴を初期化する。残したい交流は先に「ログを保存…」で保存する。
- 保存は交流途中・終了後のどちらでも可能。保存先を選び、保存後に再生一致も確認する。
  ダイアログをキャンセルすると保存しない。書き込み失敗時はエラーを表示する。

好みの入力欄は試遊条件を指定するためのもの。coreの公開観測に好みや診断スコアを追加していない。
手動試遊者は自分で設定した好みを知るため、未知の好みを推測する能力の評価には使用しない。

保存したログは既存CLIで再生できる。

```bash
python3 -m cat_cafe_sim.human_cat_demo replay path/to/human_cat_play.json
```

## 検証

通常の全テストは115件成功、画面専用2件はデスクトップ環境で別途実行して成功した（計117件）。
画面の入力処理を介した行動列がCLIのcoreと全tickで一致し、保存ログも同じ結果で再生されることを確認した。
不正条件での状態保持、再開始による履歴初期化、日本語履歴もテストしている。

実際のTkウィジェットを非表示で生成し、ボタン操作、無効行動の非実行、終了表示、再開始、
保存成功・キャンセル・I/Oエラー表示を自動検証した。目視による外観・操作感の確認は未実施。
