# 猫の行動画像プレビュー

作成日：2026-10-03

ブランチ：`feature/cat-action-preview`

通常ゲームの営業画面上部にある「猫の画像…」から、背景込みの三毛猫画像を確認できます。「通常」「遊ぶ」「撫でられる」「眠る」の4ボタンで切り替えます。同じプレビューを重複して開かず、閉じた後は再び開けます。

ゲームを始めず、内側の `cat_cafe_sim` フォルダから単独起動することもできます。

```powershell
python -m cat_cafe_sim.cafe_action_preview_gui
```

今回の画像は内蔵画像生成で作った見た目確認用の素材です。特定の所属猫への対応、行動や休養への自動連動、ローカルAI接続はまだ実装していません。プレビューのボタンはゲーム状態を変更しません。

比較用原画をアプリ内の `assets/cat_action_preview/calico-actions-v1.png` に同梱し、Tkinterで各場面を表示します。追加ライブラリは不要です。画像パスはモジュールから解決するため、作業ディレクトリには依存しません。画像が欠けている場合は代替メッセージを表示します。

次は見た目の調整後に、実際の猫ID・行動・休養状態への対応と自動切り替えを設計します。全体の希望は[相談記録](ContentToolAndRoomPresentationDiscussion.md)を参照してください。

## 検証

- WindowsのTkinterで4画像の読込、4ボタンによる画像と説明の切り替え、画像欠落時の代替表示を確認しました。
- 既存の `test_cafe_autoplay_gui.py` は12件中1件成功、表示環境を要求する11件はスキップしました。
- `git diff --check` で問題がないことを確認しました。

実際の営業画面からの操作感や異なる画面サイズでの見た目は、引き続き確認対象です。
