# 猫の行動画像プレビュー

作成日：2026-10-03

ブランチ：`feature/cat-action-preview`

通常ゲームの営業画面上部にある「猫の画像…」から、背景込みの三毛猫画像を確認できます。「通常」「遊ぶ」「撫でられる」「眠る」の4ボタンで切り替えます。同じプレビューを重複して開かず、閉じた後は再び開けます。

ゲームを始めず、内側の `cat_cafe_sim` フォルダから単独起動することもできます。

```powershell
python -m cat_cafe_sim.cafe_action_preview_gui
```

今回の画像は内蔵画像生成で作った見た目確認用の素材です。ローカルAI接続はまだ実装していません。プレビューのボタンはゲーム状態を変更しません。

## ゲーム状態との自動連動

営業画面から開くと「ゲーム状態に合わせて自動表示」が有効になります。初期対象はミケ（`playtest-mike`）、いなければ名簿の最初の猫です。猫選択欄で表示対象を変えられます。対象名と場所・状態を表示します。画像の登録はゲーム本体とは別の[制作ツール](ContentImageTool.md)で行い、ゲームは対応表を読み込みます。未登録・読込失敗時は仮の三毛猫画像です。複数の部屋の同時表示は後続です。

- 待機・交流開始直後：通常。
- 休養・療養：眠る。療養は眠る素材で代替する旨を表示。
- 接客とプレイヤー交流：最新の実行記録が「ねこじゃらし」なら遊ぶ、「なでる」なら撫でられる。
- その他の分類、休憩・切り替え・特殊行動、拒否・困惑・元気のない反応：通常画像。
- 店外：通常画像で代替する旨を表示。

準備中に休養予定の猫とプレイヤー交流した場合は、交流を優先します。交流が終わると待機・休養の表示に戻ります。自動表示は200ミリ秒ごとに現在のセッションを参照し、保存再開・新規ゲームへの切り替えにも追従します。ウィンドウを閉じると更新を解除します。

チェックを外すと4ボタンの手動確認へ戻せます。単独起動は従来どおり手動プレビューです。

比較用原画をアプリ内の `assets/cat_action_preview/calico-actions-v1.png` に同梱し、Tkinterで各場面を表示します。追加ライブラリは不要です。画像パスはモジュールから解決するため、作業ディレクトリには依存しません。画像が欠けている場合は代替メッセージを表示します。

次は制作GUIへローカル画像生成を接続し、個体別の素材と未対応行動を増やします。全体の希望は[相談記録](ContentToolAndRoomPresentationDiscussion.md)を参照してください。
