# 施設発展・来客増加・高難度のお客さん

更新日：2026-09-30 / 状態：5席、施設投資、人気3段階の追加客層まで実装済み

営業の成果を施設へ投資し、来客と猫の配置を組み直す流れをまとめます。数値と個別条件はリンク先の仕様を優先します。原案の例・旧実装順は[整理前の記録](History/2026-09-30/HumanToCatStoreDevelopmentPlan.md)に保存しています。

## 施設投資の現行範囲

| 施設 | 解放・購入と効果 | 仕様 |
| --- | --- | --- |
| 席 | 2→3席は費用500、第1段階達成後の4席と第2段階後の5席は各1,000。4・5席購入の翌営業日から通常客を各1人追加 | [増設](HumanToCatExpansion.md) |
| 接客設備 | 従来2種類と分類別3種類。1席に1個、購入済み設備の移動・取り外しは無料 | [接客設備](HumanToCatSeatEquipment.md) |
| 休養スペース | 費用400、在店休養時の疲労回復＋10 | [休養設備](HumanToCatRestEquipment.md) |
| 待合スペース | 第1段階達成後、費用800、待機上限5人・猶予10tick、日次維持費＋10 | [待合](HumanToCatWaitingArea.md) |
| 飼育スペース | 新規は6匹、費用500で9匹へ一度拡張、日次維持費＋20。人気条件なし | [飼育枠](HumanToCatHousing.md) |

席数と飼育枠は独立です。派遣中・家出中の在籍猫も飼育枠へ含め、譲渡済みと子猫は除きます。基本40＋1席10の運営費に施設の維持費を加え、営業日・休業日とも精算します。[運営費](HumanToCatOperatingCosts.md)と[日次収支](HumanToCatDailyFinance.md)で投資後の負担を確認できます。

## 人気目標による追加客層

新規の「人気3段階」で解放し、達成当日ではなく翌日以降の営業へ接続します。通常客を置き換えず追加し、人気低下後も解放を維持します。

| 達成段階 | 追加内容 | 条件・報酬の仕様 |
| --- | --- | --- |
| 第1段階 | 白猫好きのこだわり客 | [白猫と「心をつかむ」、追加料金100](HumanToCatAdvancedCustomers.md) |
| 第1段階 | 静かに過ごしたいお客さん | [静かな交流スペースと通常の静かな交流3回、追加料金150・人気3](HumanToCatQuietCustomer.md) |
| 第1段階 | 遊び好きのお客さん（火・木・土） | [キャットタワーと通常の遊び4回、追加料金180・人気4](HumanToCatPlayCustomer.md) |
| 第2段階 | 翌日の特別予約を受け入れる／見送る | [長毛と「心を開く」、追加料金200・人気5](HumanToCatReservations.md) |
| 最終段階 | 継続営業のVIP客 | [三毛と両特別行動・同時発動、追加料金400・人気10](HumanToCatVipCustomer.md) |

遊び客を導入した新規ゲームでは静かな交流客は月・水・金に来店し、曜日ごとの設備・出勤計画を組む。旧ゲームの静かな交流客の頻度は変えない。

未接客・条件未達の扱いと、自動割り当て・交流への反映は各客の仕様を参照します。最終段階のクリア結果と、その後のVIP接客は別です。休業には来店せず、旧セーブ・人気以外の開始モードへは後付けしません。

## 顧客の評価と混雑

[名簿](HumanToCatCustomers.md)と[曜日予定](HumanToCatWeekdays.md)で配置を準備し、[特徴と好み](HumanToCatCustomerPreferences.md)を担当選びに使います。[接客評価](HumanToCatCustomerSatisfaction.md)は料金・人気・常連度・不満へつながります。

[常連化](HumanToCatCustomerLoyalty.md)による週1回の追加来店、増設客、追加客層が重なるため、猫の出勤・休養・派遣と待合も調整します。[累積不満](HumanToCatCustomerDiscontent.md)による停止と[信頼回復・永久離脱](HumanToCatCustomerTrust.md)は実装済みです。

## 後続の検討

6席以上の段階・費用・客数、1席からの拡張、新しい客層、確率来店、客種別の評価・回復条件は未決定です。他モードで人気挑戦を始める経路、高難度客の別解放経路、旧セーブへの任意導入、別ゲームへの引き継ぎも未採用です。

追加時は担当可能な猫と派遣条件、混雑、購入直後と翌日の反映、通常客の維持、費用・報酬の重複防止、保存とリプレイを確認します。細かなバランス調整は全体の流れを固めてから行います。
