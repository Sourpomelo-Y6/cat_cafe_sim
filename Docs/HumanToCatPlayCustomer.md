# 遊び好きのお客さん

更新日：2026-09-30 / 状態：実装済み

## 解放・来店曜日

新規の「人気3段階」で第1段階を達成すると解放する。達成翌日以降の火・木・土の営業日に1名、開店時に来店する。固定IDは `advanced-play`。通常客を置き換えず、休業日には来店しない。

この機能を導入した新規ゲームでは、静かな交流客を月・水・金に分ける。日曜日は両客の定期来店なし。曜日はゲーム内の保存した開始曜日と日数から計算し、現実のカレンダーとは連動しない。解放後に人気が下がっても維持し、次段階への挑戦・自由営業の継続にも引き継ぐ。来店停止・永久離脱と店舗イベントの予定変更も適用する。

旧セーブ・旧リプレイへ遊び客を追加しない。遊び客の設定がない旧ゲームの静かな交流客は従来の毎日の来店を維持する。有力者・好感度・自由営業で開始したゲームにも導入しない。

## 公開条件・報酬

| 項目 | 初回仕様 |
| --- | --- |
| 席設備 | キャットタワー（購入費450） |
| 交流条件 | ねこじゃらし・ボール・ぬいぐるみ・トンネルの通常行動を合計4回以上 |
| 達成報酬 | 追加料金180・追加人気4（暫定） |
| 未達・未接客 | 固有の追加料金・人気0。通常の会計と評価を維持 |

実際の通常行動を数え、切り替え・休む・特別行動は含めない。反応や関心上昇量によらず回数を判定する。猫の特徴に必須条件を付けず、通常の特徴への好みは開始シードから固定する。

接客終了時に設備と回数を判定し、通常会計・特別行動・満足ボーナスに固有の料金を加算する。手動終了・閉店・体力切れでも終了までの実績を使う。条件達成は満足評価＋1、未達は−1で、評価から常連度・不満へ接続する。独立した罰金はない。追加人気は閉店時に精算し、既存の上限とゲームオーバー優先を適用する。

## 操作・自動接客

名簿の当日／翌日の予定と曜日欄、選択した客の詳細に解放・条件・報酬・直近結果を表示する。営業ログにも解放と接客結果を表示する。

手動割り当てでは設備のある席と猫を選ぶ。自動割り当ては、この客を割り当てる時点で空いているキャットタワーの席を優先し、なければ通常の空席を使う。待機列の順序や接客中の客を変更しない。

対象客の自動交流は猫の得意分類より遊びを優先する。種類は猫の個性と基本効果で選び、同じ分類を2回続けた後は別分類を挟む既存方策を使う。体力・特別行動への対応、熟練と設備の倍率は既存どおりで、客条件の優先による追加倍率は付けない。

## 保存・検証

`config/cafe_play_customer.json` の設備・回数・料金・人気・両客の来店曜日を新規開始時に任意項目 `play_customer` へ固定する。再開時に設定ファイルを読み直さない。解放日は人気目標の履歴から導出する。

対象客の交流設定にだけ `play_service: true` を保存し、成果へ接客開始時の設備一致 `play_equipment` を記録する。回数は従来の `type_actions` から導出する。通常客・旧ログには新しい設定項目を出力しない。設備の取り外し後も過去の評価を変えず、保存失敗の再試行で報酬を二重加算しない。

1席／複数席、設備一致・不一致、4回・3回・0回、特別行動除外、自動接客、会計・人気、設備移動後の過去結果、未接客、保存失敗と再試行、曜日分離と旧静かな交流客の互換、他モード、設定固定、不正データ、保存再開・詳細リプレイ、名簿の条件・結果と最小サイズを確認する。

検証結果：仮想ディスプレイでGUIを含む全670件成功（追加12件）。差分チェックとローカルリンクの確認も成功。

[触れ合い好きのお客さん](HumanToCatContactCustomer.md)を導入した新規の人気モードでは、第1段階達成の翌日以降の日曜日に1名来店する。お手入れブラシの席で通常の触れ合い3回以上を行うと追加料金160・人気3。既存の遊び客・静かな交流客の来店設定と旧セーブは維持する。
