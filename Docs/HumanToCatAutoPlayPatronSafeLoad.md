# 有力者向け自動プレイの負担予測・育成・休養

更新日：2026-10-03。変更前は[3人の有力者の10シード評価](HumanToCatPatronMembersSeedEvaluation.md)で発症265回・家出45回があった。ユーザーの依頼に沿い、有力者の安定・積極経営の判断を改善した。人気・好感度の判断、基礎営業、満足度・育成・健康・派遣の係数、席数・猫数・保存形式は変更しない。基準は `7c10552`（ゲーム実装は `adf738e`）。

積極経営は後続で[希望に合う猫の確保と派遣待ち](HumanToCatAutoPlayPatronFast.md)を追加した。本書の共通の派遣経路・黒猫加入未採用という説明と比較値は、方針を分ける前の記録として維持する。安定経営の判断は引き続き本書の内容を使う。

## 原因と変更

有力者モードでは、派遣後の営業判断に基礎営業の「現在の疲労・ストレス60未満なら出勤」を使っていた。接客好きの特性や、その日の接客が一匹へ集中した場合の増加を見込まず、出勤時は条件内でも閉店後に疲労60・ストレス80を超え得た。派遣に使う猫の育成・休養も、通常の出勤と競合していた。

有力者向けの営業は、保存済み来店予定から既存の[集中負担予測](HumanToCatAutoPlaySafeLoad.md)を使い、出勤時の予測疲労・ストレスがともに60以下の猫を必要人数まで選ぶ。安定・積極経営の有力者経路は共通で、安全側の予測を使う。人気・好感度に適用する既存の安定・積極経営は維持する。

厳格型が未達の場合、接客の得意分野を未選択の白猫一匹を育成役として、安全な範囲で出勤を優先する。育成中のその猫は他の有力者へ派遣しない。接客の得意分野を持つ白猫が確保できたら一匹を派遣役として休養させ、他の猫は通常の出勤判断に戻す。譲渡済みの猫は役割から除外する。厳格型達成後は役割による優先・休養を解除する。旧一人の目標では白猫の役割を後付けしない。

派遣には既存の健康・疲労40以下・余剰猫等の条件に加え、自動プレイ側でストレス60以下まで休養を待つ。これは通常派遣の参加条件の変更ではない。相手の順序、予定加点の高い候補の優先、全体で同時一件の訪問は維持する。黒猫加入・条件一致まで待つ方針・同時派遣・設備投資・増席は追加しない。

安全な出勤候補がいなければ休業する。受諾済みの予約当日は休業できないため、安全な候補がなければ出勤なしで営業を進める。予約への対応を理由に安全条件を超える猫を出勤させない。判断ログには予測負担、白猫の育成優先、派遣役の休養、不在・療養を表示する。ゲームの操作は通常の出勤設定・派遣・休業・接客だけを使う。
