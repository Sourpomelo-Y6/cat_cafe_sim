# テンションと特別行動：版2の実装記録

更新日：2026-09-11 / 単独交流ルール版：2

[暫定仕様](HumanToCatSpecialActionsSpecification.md)に沿って、テンション、ゲージ80消費、
任意／強制発動、同時発動、資金ボーナス、両側の発動による成功条件を実装した。
数値は`config/human_cat_special.json`に保存し、今回の比較後も変更していない。

## 操作

試遊画面は既定で版2を使う。

```bash
python3 -m cat_cafe_sim.human_cat_gui
# 初期版の試遊
python3 -m cat_cafe_sim.human_cat_gui --rules 1
```

テンションゲージ、「心をつかむ」ボタン、両側の次回予約、発動回数と獲得資金を追加した。
履歴にもテンションとそのtickの獲得資金を表示する。
強制予約がある間は心をつかむ以外を選べず、猫側の行動は固定方策が開始状態から決める。
関心100では即終了せず、両側が各1回以上発動すれば成功する。体力0による終了が優先。
資金は単独交流のボーナス累計であり、営業の財布にはまだ接続していない。

CLIは旧コマンドの挙動を維持するため既定が版1。版2では`--rules 2`を指定する。

```bash
# 仕様書の同時発動例。初期ゲージ指定は診断用。
python3 -m cat_cafe_sim.human_cat_demo run --rules 2 \
  --tension 80 --engagement 80 --actions connect
python3 -m cat_cafe_sim.human_cat_demo replay reports/human_cat_special_session.json

# 固定方策比較
python3 -m cat_cafe_sim.human_cat_demo compare --rules 2
```

同時発動例はテンション10・関心0・体力100・資金200で成功する。
`--config`で別設定を読み込める。版2のrunとcompareは既定出力名に`special`を付け、版1の既定出力と分ける。
新版では初期ゲージを0〜上限で検証し、100以上の初期値から強制予約を導出する。
予約中の別行動入力、資格のないconnectは状態を変えず拒否する。

## 共有処理と互換性

版1の通常行動処理を共通メソッドへ抽出し、版2はそれを使って通常反応・関心効果・体力・飽き履歴を計算する。
猫だけopen_upした場合も通常行動の関心効果は処理するが、テンションはopen_upの+10のみ。
connect時は通常効果と体力消費を発生させず、停止連携を切り、通常反応の履歴を「なし」にする。

新版ログはルール版2、初期ゲージ、両側の行動と発動根拠、通常反応、消費と増減、超過分、
予約失効、ボーナス内訳を持つ。次回予約の成立は各tickのafter状態に保存する。
保存再生は版から処理を振り分け、旧版を新版として読み替えない。
既存の猫学習モデル・営業ルール・旧設定は変更していない。

## 固定方策32条件の結果

好み(1,1)、(0,2)、(2,0)、(0.5,0.5)×開始体力100／20×4方策を比較した。
開始ゲージはいずれも0。全ログの再生一致を確認した。

| 方策 | 成功 / 8 | 時間切れ / 8 | 平均資金 | 平均体力消費 | 平均tick | 平均同時発動回数 |
|---|---:|---:|---:|---:|---:|---:|
| immediate：任意発動可能なら即発動 | 3 | 5 | 62.50 | 36.88 | 17.62 | 0.25 |
| synchronize：両側の発動機会を待つ | 3 | 5 | 75.00 | 35.62 | 17.25 | 0.38 |
| repeat：素直を反復し、可能なら即発動 | 2 | 6 | 37.50 | 50.62 | 18.25 | 0.12 |
| pause：停止のみ（強制予約は優先） | 0 | 8 | 0.00 | 0.00 | 20.00 | 0.00 |

すべての方策は公開観測だけを使う。体力20以下では停止する固定条件を持つ。
immediateとsynchronizeは、そっぽを向く反応または同種類2連続後に種類変更する。
synchronizeはお客の発動資格に加えて猫の関心が任意閾値以上または猫の予約ありの場合にconnectする。
強制予約はどの方策でも最優先。repeatは切り替えず、片側反復の候補として比較する。

今回の条件では消耗終了・失効予約は0件だった。境界条件は別途テストした。
平均資金の差はこの少数の固定条件での結果であり、最適性や学習性能の証明ではない。
通常／低体力の個別結果、両側発動回数、反応内訳、失効予約数は
`reports/human_cat_special_comparison.json`、各tickは同名ディレクトリに保存する。
生成物は従来どおりGit管理外。
