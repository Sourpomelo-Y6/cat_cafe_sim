# 静かな読書サロンへの派遣

更新日：2026-09-30 / 状態：派遣先と専用の選択イベントを実装済み

[のんびり屋](HumanToCatTraits.md)の猫を店で休養させるか、報酬のために派遣するかを選べる担当先。数値は暫定です。

## 解放と参加条件

新規ゲームの全モードに追加します。人気120以上かつ派遣報酬1回受取で解放し、人気が下がっても維持します。出発・帰還確認待ち・重複受取・報酬なしの中断帰還は受取回数へ加えません。

| 項目 | 仕様 |
| --- | --- |
| ID / 名前 | `quiet_reading_salon` / 静かな読書サロン |
| 派遣期間 | 2日 |
| 基本報酬 | 300（派遣全体の額） |
| 必要特性 | のんびり屋（保存済みID `relaxed` で判定） |
| 疲労上限 | 40以下 |

健康で担当可能な在店猫が対象です。店内の席数を超える担当可能な猫が必要で、同じ猫の二重派遣・同日再派遣はできません。営業準備中に「準備・お店」→「派遣・帰還を確認する…」から選び、解放の進捗、特性・疲労条件、日数・報酬を確認できます。確認のキャンセルでは変更しません。営業中・閉店後・結果保存待ち・プレイヤー交流中・未解決イベント・ゲームオーバーなどの制限は[派遣仕様](HumanToCatCafeActivities.md)と共通です。

## 読書サロンだけの延長イベント

これから出発する読書サロンの派遣に、1日目終了時の「延長の触れ合いをお願いされました」を設定します。出発確認で予告し、回答まで営業・翌日・休業を止めます。派遣期間は2日のままです。

| 選択 | 帰還報酬の増減 | 回答時の疲労 | 回答時のストレス |
| --- | ---: | ---: | ---: |
| 延長の触れ合いに参加する | ＋80 | 変化なし | ＋10 |
| 予定どおり終える | 変化なし | 変化なし | 変化なし |

ストレス10は固定加算で上限100へ制限します。特性の接客・休養倍率は掛けません。追加報酬は回答時に入金せず、成長補正済みの基本報酬へ80を加え、帰還受取時に一度だけ精算します。派遣得意なら300×1.1＋80＝410です。家出トラブル、猫紹介、アイテム報酬は設定しません。

営業日・休業日とも1日ずつ進み、派遣中は店内の接客・休養から外れます。のんびり屋の在店疲労回復は派遣中には適用しません。帰還確認・報酬受取まで進行を停止し、資金・派遣経験を一度だけ反映します。帰還後の出勤予定は準備中に選び直します。イベントの状態変化・結果内訳は[派遣中の選択イベント](HumanToCatDispatchEncounters.md)に従います。

## 保存と互換性

開始時に [cafe_dispatch_unlocks.json](../config/cafe_dispatch_unlocks.json) の解放条件・派遣先を任意の `dispatch_unlocks.rules.quiet_reading_salon` に固定し、解放日と達成時の人気・受取回数を保存します。出発時に [cafe_dispatch_encounters.json](../config/cafe_dispatch_encounters.json) の専用イベントを既存の任意項目 `encounter` へ固定します。設定変更後も保存済みの期間・報酬・条件・選択効果を使います。

旧の2派遣先だけ、運動教室を含む3件、解放ルールなしの保存を引き続き読み込めます。読書サロンは旧ゲームへ後付けせず、一覧にも追加しません。既存派遣・出発済み記録の選択イベント・宿の家出条件は変更しません。イベントのない出発済み記録にも新しいイベントを追加しません。

営業セーブ形式2・チェックポイント1・詳細リプレイ4を維持します。復元時に派遣先と開始時設定、解放前の出発、残日数・選択と効果・資金の整合性を確認します。選択待ち・帰還待ち・受取後の保存再開と詳細再生、保存失敗後の再試行に対応し、ストレス・経験・報酬を二重処理しません。
