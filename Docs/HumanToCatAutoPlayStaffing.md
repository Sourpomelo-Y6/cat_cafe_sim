# クリア方針の来店予定・出勤・増設判断

更新日：2026-10-02。人気第1段階後の通常客増加に合わせ、「クリアを目指す」の準備判断を改善した。「基礎営業」、人気目標・期限・料金・猫の係数・保存形式は維持する。

## 判断ルール

- 保存済みの今日の来店予定を使い、曜日・常連・予約・雨・来店停止・永久離脱を反映する。翌日の未確定イベントを予測しない。
- 来店時点から通常の交流時間までの重なりを、同時接客の見込みとして数える。閉店後までの交流時間は数えない。
- 接客量を20行動ずつ分担する人数と同時接客の見込みのうち多い方を出勤人数の目安とする。在店している健康で担当可能な猫の数を上限にする。
- 接客量の見積もりは既存席数×営業時間を上限とし、出勤人数の目安で分担する。初日や実績の少ない日も、猫1匹につき最低20行動を見込む。前日の負担を今日もそのまま繰り返す前提は外す。
- 疲労・ストレスが小さい猫から選び、出勤後の予測疲労・ストレスがともに60以下の候補を、必要人数まで出勤させる。残りは休養させ、来店がない日や候補がいない日は休業する。予約当日は従来の休業回避を維持する。
- 出勤候補数または同時接客の見込みが既存席数以下なら増設を見送る。両方が既存席数を上回る日だけ、解放条件・期限・費用・予備資金を満たす席購入を行う。

休養設備・おもちゃ・防音改修・予約の条件と予備資金の計算は従来どおり。担当の割り当てと交流コマンドは通常処理に任せる。来店数・同時接客の見込み・候補数、購入／見送り理由、猫ごとの負担と出勤／休養理由を日本語ログとGUIの判断一覧へ表示する。

予測は接客が各猫へ分散する目安で、好みの一致による担当の偏り、早期終了、待機による来店時点との差までは再現しない。予測60以下でも実際の負担や発症を保証しない。読み取りだけで時間・好み・関係・乱数・ファイルを変更せず、毎回保存済みの現在状態から判断する。既存セーブの再開にも使えるが、新旧方針の将来の判断が同じになる保証はしない。過去の成果と詳細リプレイは維持する。
