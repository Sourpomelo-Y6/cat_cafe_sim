# 飼育スペースと受け入れ上限

更新日：2026-09-30 / 状態：初回実装済み

## 初回仕様

新規ゲームでは、接客席数とは別に在籍猫の上限を6匹とする。「準備・お店」→「飼育スペースを拡張する…」から費用500で一度だけ購入し、上限を9匹へ増やせる。人気や目標達成による解放条件は設けない。好感度目標の6匹へは購入なしでも到達できる。

在籍数には在店・派遣中・家出中・療養中の猫を含め、譲渡済みは除く。譲渡済みの猫の記録は削除せず、空いた枠へ別の猫を迎えられる。外部へ引き渡す子猫は従来どおり費用だけで扱い、在籍猫にも飼育枠にも含めない。席数・派遣の参加条件は変更しない。

初期上限6、拡張幅3、購入費500、維持費20は設定ファイル `config/cafe_housing.json` の暫定値。細かなバランス調整、複数段階の拡張、売却・返金は後続とする。

## 受け入れと満員時の操作

通常候補画面と受け入れ依頼画面に、在籍数・上限・空き枠を表示する。満員では迎える操作を無効にし、処理側でも拒否する。拒否時は猫の登録、在籍状態、資金、回答記録を変えない。候補の閲覧・定期追加は維持する。

依頼への回答待ちは既存仕様どおり準備の変更も止めるため、満員のまま依頼が届いた場合は「見送る」で進行できる。見送りによる費用・人気の変化はない。その猫を迎えたい場合は、依頼発生前に枠を確保する。

拡張は営業準備中だけ購入でき、支払い後に資金が残る必要がある。未解決イベント、目標結果、成長選択、プレイヤー交流中、接客結果の保存待ち、ゲームオーバー時は購入できない。確認のキャンセルでは何も変更しない。

## 会計・保存・詳細リプレイ

購入当日から上限を増やし、日次の店舗運営費に維持費20を追加する。営業日・休業日の両方に一度だけ精算し、資金0以下なら既存のゲームオーバーを適用する。購入費は日次収支と比較画面の「飼育スペース費用」、維持費は「運営費」に含める。営業ログにも購入結果と運営費の飼育分を表示する。

営業セーブ形式2・チェックポイント1に任意項目 `housing` を追加し、新規開始時のルールと購入日・金額を固定保存する。設定ファイルの後日の変更で上限・費用を変えない。復元時には購入記録、在籍数と上限、日次費用、運営費の内訳、資金の整合性を確認する。詳細リプレイ4では初期化・購入と日次精算を再現する。保存失敗時も購入結果を保持し、再保存で二重請求しない。

旧セーブには上限・購入・維持費を後付けせず、上限なしの従来ルールと既存の加入経路を維持する。既に6匹以上いる猫を削除・強制譲渡しない。旧セーブの画面は「上限なし（従来ルール）」と表示し、拡張購入は不要と案内する。
