# 猫の経験・得意分野と接客熟練

更新日：2026-09-30 / 状態：活動経験、得意分野、3分類から最大2分類の接客熟練・8種類から最大2つ選ぶ個別行動熟練、自動交流と判断画面への反映を実装済み

現在の成長ルールと後続範囲をまとめます。必要経験・効果の暫定値は下記の実装済み仕様を用います。原案の未決定事項と効果候補は[整理前の記録](History/2026-09-30/HumanToCatCatGrowthPlan.md)に保存しています。

## 初回実装

新規ゲームでは、接客完了・在店休養日の終了・派遣報酬の受取ごとに対応する経験を1獲得する。合計20で得意分野を1つ選ぶ。回答するまで営業開始、休業、翌日進行などを止める。

| 得意分野 | 初回効果 |
| --- | --- |
| 接客 | 接客終了時に、その接客で消費した体力の10%を回復 |
| 休養 | 在店休養時の疲労回復＋5 |
| 派遣 | 選択後に出発した派遣の報酬を1.1倍 |

接客経験と同時に、8種類の行動回数と、遊び・触れ合い・静かな交流の分類別回数を保存する。全行動の回数は表示用に保持し、個別行動熟練の習得対象実績とは別に扱う。

接客を得意分野に選んだ猫は、親しみが実際に増えた接客で行った通常行動を、接客熟練の対象実績として別に蓄積する。対象実績が合計15になると、その猫に実績がある「遊び」「触れ合い」「静かな交流」から得意な交流を1つ選ぶ。選んだ分類では、通常行動による関心増加を1.1倍にする。親しみが増えなかった接客は対象実績へ加えないため、失敗行動の反復だけでは習得できない。

自動交流は接客開始時に得意分類を優先し、その中では猫の個性と行動の基本効果から種類を選ぶ。同じ分類を2回続けた後はいったん別分類へ切り替えて飽きを抑え、そこで2回交流した後に得意分類へ戻る。得意分類への切り替えは営業ログにも示す。

猫の詳細画面で経験、分類別実績、得意分野を確認できる。日次実績にはその日の接客・休養・派遣経験を表示し、得意分野の選択はできごとにも残す。新規加入猫は加入後から0で開始する。

営業画面の猫一覧、出勤・休養画面、派遣画面には、経験の進捗または選択済みの得意分野を表示する。選択中の猫については、活動別経験、3分類の接客実績、次の成長までの残り、または現在適用される効果を表示する。派遣画面の報酬見込みには得意分野の倍率も反映する。

## 個別行動熟練

分類熟練を選んだ後、選択済み分類で親しみが実際に増えた接客の通常行動を別に蓄積する。分類内の合計30回で、実績がある行動を1つ選ぶ。分類習得前の行動、他分類、親しみが増えなかった接客、切り替え・休憩・特別行動は対象にしない。初回枠は猫ごとに1行動で、追加枠でもう1行動を習得できる。個別行動熟練は最初の得意分類内で習得する。再選択は対象外。

| 分類 | 選択できる行動 |
| --- | --- |
| 遊び | ねこじゃらし、ボール遊び、ぬいぐるみ遊び、トンネル遊び |
| 触れ合い | なでる、ブラッシング |
| 静かな交流 | 声をかける、そばで見守る |

選んだ行動の正の通常関心上昇を追加で1.05倍にする。個性の好み・分類熟練1.1倍・分類別設備1.35倍と乗算し、すべて一致した場合は1.55925倍。消費体力、テンション、特別行動の条件は直接変えない。数値は `config/cafe_growth.json` の `type_mastery_threshold` と `type_mastery_engagement_multiplier` で新規ゲーム開始時に固定する。

自動交流は客の指定分類を優先し、その分類に得意な行動があれば優先して選ぶ。通常客では得意分類の中で個別熟練を優先する。低体力時の休憩、特別行動、飽きを抑える別分類への切り替えは維持する。習得前・旧ルールの自動交流は変えない。

条件を満たすと営業画面に選択の案内を表示し、回答まで営業・休業・翌日進行を止める。選択画面は実績のある候補だけを表示する。猫の詳細には8種類の習得対象実績と得意な行動、各配置画面には進捗または効果、猫のできごとと営業ログには選択結果を表示する。

## 2つ目の個別行動熟練

新規ゲームでは、最初の個別熟練習得後に、同じ得意分類の未習得行動で親しみが増えた接客の通常行動を別に蓄積する。合計30回で、実績のある未習得行動を1つ選ぶ。初回習得前の実績、初回の得意行動、他分類、親しみが増えなかった接客、切り替え・休憩・特別行動は加算しない。例えば「なでる」を習得済みなら、追加実績で「ブラッシング」を選べる。

最大2行動で、3つ目や再選択は行わない。初回行動と2つ目の行動それぞれに通常関心上昇1.05倍を適用し、同じ行動に2回掛けない。既存の分類熟練・設備とは乗算する。追加条件は `config/cafe_growth.json` の `second_type_mastery_threshold` として開始時に固定する。

2行動を習得した猫の自動交流は、客の指定分類または得意分類の中で、個性の好み・基本効果・個別熟練補正を含む比較から種類を選ぶ。2行動を順番に必ず使うルールは設けず、低体力時の休憩・特別行動・分類単位の飽き対策を維持する。1行動までの既存の自動交流は変更しない。

追加実績が条件を満たすと、既存の成長案内から2つ目の選択画面を開く。回答まで進行を止め、候補から初回行動と実績のない行動を除く。猫の詳細・活動の選択画面に両行動と追加実績の進捗を表示し、できごと・営業ログに2つ目の選択を残す。

追加条件を持たない旧セーブ・旧ログには、この実績や選択を後付けしない。初回個別熟練までの旧形式とその自動交流を維持する。選択待ち、選択後、両行動を使う接客中の保存再開と詳細リプレイに対応し、保存失敗の再試行で実績や選択を二重処理しない。

## 2つ目の接客分類熟練

新規ゲームでは、最初の分類を習得した後、未習得の各分類で親しみが実際に増えた接客の通常行動を別に蓄積する。1分類の実績が30回に達すると、その分類を2つ目の得意な交流に選べる。2分類に15回ずつのような合算では習得できない。初回習得前、最初の得意分類、親しみが増えなかった接客、切り替え・休憩・特別行動は加算しない。複数の候補が条件を満たした場合は、その中から1つ選ぶ。

最大2分類で、それぞれの正の通常関心上昇を1.1倍にする。同じ行動に分類補正を2回掛けない。設備・個別行動熟練とは既存どおり乗算し、体力消費・テンション・特別行動は直接変えない。個別行動熟練は最初の分類内で最大2行動を維持し、2つ目の分類には個別習得枠を追加しない。条件は `config/cafe_growth.json` の `second_mastery_threshold` として開始時に固定する。

自動接客は客の指定分類を優先し、通常客は最初の得意分類を基本にする。別分類に切り替える飽き対策、低体力時の休憩、個性による行動選択を維持する。2つ目の分類を習得した場合も、全員にその分類を強制しない。

既存の成長案内・選択画面から選び、回答まで営業・休業・翌日進行などを止める。候補は実績30回に達した未習得分類のみ。猫の詳細と配置画面に両分類と進捗、できごとと営業ログに選択結果を表示する。個別行動の選択と同時に条件を満たした場合は、分類選択を先に案内し、続いて個別行動を選ぶ。

追加条件のない旧セーブ・旧ログには実績・選択・効果を後付けしない。新規加入猫は加入後から0で開始する。追加実績・分類・選択日を成長記録に保存し、接客中は2つ目の分類も接客条件として固定する。選択待ちと接客中の保存・再開、詳細リプレイ、保存失敗後の再試行に対応する。

## 既存要素との区分

| 要素 | 意味 | 成長による変更 |
| --- | --- | --- |
| 個性・好み | 8種類の交流、強さ、飽き、切り替えに対する生来の傾向 | 初回は変更しない |
| 特性 | 接客好き、のんびり屋、外出好きなどのパッシブ効果 | 初回は変更・追加しない |
| 特徴 | 毛色・柄、毛の長さなど、お客さんの好みと照合する属性 | 経験では変更しない |
| 経験・熟練度 | 実際に担当した活動から得る後天的な成長 | 活動経験・得意分野・3分類の熟練・個別行動熟練を保存 |

苦手な行動を繰り返しただけで個性や好みを反転させない。生来の傾向と後天的な上達を別々に表示・保存する。

## 設備・追加客層との組み合わせ

[分類別の接客設備](HumanToCatSeatEquipment.md)は対応分類の通常関心上昇を1.35倍にし、熟練の1.1倍と乗算します。テンション、消費体力、特別行動の条件は直接変えません。

[静かな交流客](HumanToCatQuietCustomer.md)の自動接客では、得意分類より客の静かな交流条件を優先します。熟練の効果そのものは選択済み分類に従い、客条件を優先しただけで追加倍率は付きません。

## 保存と互換性

- 新規ゲームでのみ成長ルールを有効化し、旧セーブへ経験値を推測して後付けしない。
- 個別熟練の設定がない旧セーブ・旧ログには、新しい実績・習得条件・効果を追加しない。得意分野だけ、または3分類熟練までの旧形式を引き続き読み込む。
- 個別熟練の選択待ち・接客中も保存再開できる。対象実績・選択日・効果を保存し、再開や保存失敗の再試行で実績と選択を重複させない。
- ルール、猫別経験、成長選択、選択日を営業セーブへ保存する。
- 保存再開や画面の開き直しで経験・選択回数を二重加算しない。
- 譲渡済みや行方不明の猫も過去の経験と成長履歴を保持する。
- 加入した猫は加入後の活動だけを経験へ加算する。
