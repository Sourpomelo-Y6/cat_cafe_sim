# 猫の経験・得意行動の成長案

2026-09-30追記：[分類別の接客設備](HumanToCatSeatEquipment.md)を3種類追加。キャットタワー・お手入れブラシ・静かな交流スペースを各450で購入し、遊び・触れ合い・静かな交流の一致する通常の関心上昇だけ1.35倍にする。熟練と乗算し、価格・効果・条件の表示、配置、収支、保存とリプレイへ接続。従来2種類の効果と旧保存済み設定を維持する。

更新日：2026-09-29 / 状態：活動経験、得意分野、3分類の接客熟練、自動交流への反映、営業前の判断画面への表示を実装済み。8種類の個別行動熟練は未実装

## 初回実装

新規ゲームでは、接客完了・在店休養日の終了・派遣報酬の受取ごとに対応する経験を1獲得する。合計20で得意分野を1つ選ぶ。回答するまで営業開始、休業、翌日進行などを止める。

| 得意分野 | 初回効果 |
| --- | --- |
| 接客 | 接客終了時に、その接客で消費した体力の10%を回復 |
| 休養 | 在店休養時の疲労回復＋5 |
| 派遣 | 選択後に出発した派遣の報酬を1.1倍 |

接客経験と同時に、8種類の行動回数と、遊び・触れ合い・静かな交流の分類別回数を保存する。現段階では表示と将来拡張用の記録であり、個々の行動には熟練効果を付けない。

接客を得意分野に選んだ猫は、親しみが実際に増えた接客で行った通常行動を、接客熟練の対象実績として別に蓄積する。対象実績が合計15になると、その猫に実績がある「遊び」「触れ合い」「静かな交流」から得意な交流を1つ選ぶ。選んだ分類では、通常行動による関心増加を1.1倍にする。親しみが増えなかった接客は対象実績へ加えないため、失敗行動の反復だけでは習得できない。

自動交流は接客開始時に得意分類を優先し、その中では猫の個性と行動の基本効果から種類を選ぶ。同じ分類を2回続けた後はいったん別分類へ切り替えて飽きを抑え、そこで2回交流した後に得意分類へ戻る。得意分類への切り替えは営業ログにも示す。

猫の詳細画面で経験、分類別実績、得意分野を確認できる。日次実績にはその日の接客・休養・派遣経験を表示し、得意分野の選択はできごとにも残す。新規加入猫は加入後から0で開始する。

営業画面の猫一覧、出勤・休養画面、派遣画面には、経験の進捗または選択済みの得意分野を表示する。選択中の猫については、活動別経験、3分類の接客実績、次の成長までの残り、または現在適用される効果を表示する。派遣画面の報酬見込みには得意分野の倍率も反映する。

## 目的

接客・休養・派遣を繰り返した猫に成長を持たせ、同じ初期特性の猫でも担当した仕事とプレイヤーの選択によって違いが生まれるようにする。

接客経験は、将来「特定の交流行動が得意になる」仕組みへ発展できるようにする。初回から保存形式を単一の合計値だけに固定せず、行動別熟練度を追加できる構造を採用する。

## 既存要素との区分

| 要素 | 意味 | 成長による変更 |
| --- | --- | --- |
| 個性・好み | 8種類の交流、強さ、飽き、切り替えに対する生来の傾向 | 初回は変更しない |
| 特性 | 接客好き、のんびり屋、外出好きなどのパッシブ効果 | 初回は変更・追加しない |
| 特徴 | 毛色・柄、毛の長さなど、お客さんの好みと照合する属性 | 経験では変更しない |
| 経験・熟練度 | 実際に担当した活動から得る後天的な成長 | 新しく追加する |

苦手な行動を繰り返しただけで個性や好みを反転させない。生来の傾向と後天的な上達を別々に表示・保存する。

## 経験の分類案

- **接客経験**：通常営業で接客を完了すると増える。
- **休養経験**：休養予定で一日を終えると増える。
- **派遣経験**：派遣を完了し、帰還結果を確定すると増える。

接客経験には合計値を持たせつつ、将来は次の行動分類別熟練度を追加できるようにする。

- 触れ合い
- 静かな交流
- 遊び
- 必要であれば8種類の個別行動

分類は既存の個性表示や飽き判定で使う行動分類との共用を優先する。交流1ターンごとの全履歴を営業セーブへ保存するのではなく、確定済み接客結果から必要な回数を集計するか、分類別の累計値だけを保存する。

## 初回の成長案

最初は活動経験が一定値に達した猫について、得意分野を1つだけ選ぶ。これは上記の内容で初回実装済み。

| 選択 | 効果の方向性 |
| --- | --- |
| 接客強化 | 接客時の体力消費を軽減する |
| 休養強化 | 在店休養時の疲労回復を増やす |
| 派遣強化 | 派遣完了時の報酬を増やす |

成長可能になった時点で選択待ちにし、回答するまで営業開始・休業・翌日進行を止める。選択内容は猫の詳細、できごと、日次結果、セーブ、詳細リプレイに残す。

初回の数値、必要経験、複数回の成長、振り直しは未決定とする。全体の流れを先に確認するため、最初は1匹につき1回の選択に限定する案とする。

## 将来の行動別熟練度

接客成長の次段階として、成功した接客を3分類別に蓄積し、得意な交流を選ぶ初回機能を実装した。

候補となる効果は次のとおり。

- その行動の体力消費を軽減する。
- 実装済み：選んだ3分類の関心の通常増加を1.1倍にする。
- 苦手な行動による不利を一部だけ緩和する。
- 特別行動の発動条件を直接下げず、通常行動の結果を通して到達しやすくする。

熟練対象の判定には、接客終了時に親しみが実際に増えたことを使う。接客中の個々の行動が好反応だったかではなく、その接客全体の確定結果で判定する。8種類の個別熟練、複数分類の習得、再選択は後続とする。

## 保存と互換性

- 新規ゲームでのみ成長ルールを有効化し、旧セーブへ経験値を推測して後付けしない。
- ルール、猫別経験、成長選択、選択日を営業セーブへ保存する。
- 保存再開や画面の開き直しで経験・選択回数を二重加算しない。
- 譲渡済みや行方不明の猫も過去の経験と成長履歴を保持する。
- 加入した猫は加入後の活動だけを経験へ加算する。

## 実装前に決める事項

- 経験を得る単位と必要量。
- 接客完了、接客評価、個々の行動のどれを加算条件にするか。
- 8種類の個別行動へ熟練効果を広げるか。
- 体力消費、疲労、報酬への暫定効果量。
- 特性と成長効果が重なる場合の計算順序。
- 自動交流方策は選択済みの得意な交流を判断基準として参照する（実装済み）。
