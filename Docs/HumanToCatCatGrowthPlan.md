# 猫の経験・得意行動の成長案

更新日：2026-09-29 / 状態：計画案、未実装

## 目的

接客・休養・派遣を繰り返した猫に成長を持たせ、同じ初期特性の猫でも担当した仕事とプレイヤーの選択によって違いが生まれるようにする。

接客経験は、将来「特定の交流行動が得意になる」仕組みへ発展できるようにする。初回から保存形式を単一の合計値だけに固定せず、行動別熟練度を追加できる構造を採用する。

## 既存要素との区分

| 要素 | 意味 | 成長による変更 |
| --- | --- | --- |
| 個性・好み | 8種類の交流、強さ、飽き、切り替えに対する生来の傾向 | 初回は変更しない |
| 特性 | 接客好き、のんびり屋、外出好きなどのパッシブ効果 | 初回は変更・追加しない |
| 特徴 | 毛色・柄、毛の長さなど、お客さんの好みと照合する属性 | 経験では変更しない |
| 経験・熟練度 | 実際に担当した活動から得る後天的な成長 | 新しく追加する |

苦手な行動を繰り返しただけで個性や好みを反転させない。生来の傾向と後天的な上達を別々に表示・保存する。

## 経験の分類案

- **接客経験**：通常営業で接客を完了すると増える。
- **休養経験**：休養予定で一日を終えると増える。
- **派遣経験**：派遣を完了し、帰還結果を確定すると増える。

接客経験には合計値を持たせつつ、将来は次の行動分類別熟練度を追加できるようにする。

- 触れ合い
- 静かな交流
- 遊び
- 必要であれば8種類の個別行動

分類は既存の個性表示や飽き判定で使う行動分類との共用を優先する。交流1ターンごとの全履歴を営業セーブへ保存するのではなく、確定済み接客結果から必要な回数を集計するか、分類別の累計値だけを保存する。

## 初回の成長案

最初は活動経験が一定値に達した猫について、得意分野を1つだけ選ぶ。

| 選択 | 効果の方向性 |
| --- | --- |
| 接客強化 | 接客時の体力消費を軽減する |
| 休養強化 | 在店休養時の疲労回復を増やす |
| 派遣強化 | 派遣完了時の報酬を増やす |

成長可能になった時点で選択待ちにし、回答するまで営業開始・休業・翌日進行を止める。選択内容は猫の詳細、できごと、日次結果、セーブ、詳細リプレイに残す。

初回の数値、必要経験、複数回の成長、振り直しは未決定とする。全体の流れを先に確認するため、最初は1匹につき1回の選択に限定する案とする。

## 将来の行動別熟練度

接客成長の次段階として、実行回数や成功した接客を行動分類別に蓄積し、よく使った行動を得意にする。

候補となる効果は次のとおり。

- その行動の体力消費を軽減する。
- 関心またはテンションの通常増加を少し上げる。
- 苦手な行動による不利を一部だけ緩和する。
- 特別行動の発動条件を直接下げず、通常行動の結果を通して到達しやすくする。

熟練度の上昇判定は、単に実行した回数だけにするか、満足・親しみ増加などの良い結果を必要とするか未決定。短い接客の反復や失敗行動の連打が最適にならない条件を実装前に決める。

## 保存と互換性

- 新規ゲームでのみ成長ルールを有効化し、旧セーブへ経験値を推測して後付けしない。
- ルール、猫別経験、成長選択、選択日を営業セーブへ保存する。
- 保存再開や画面の開き直しで経験・選択回数を二重加算しない。
- 譲渡済みや行方不明の猫も過去の経験と成長履歴を保持する。
- 加入した猫は加入後の活動だけを経験へ加算する。

## 実装前に決める事項

- 経験を得る単位と必要量。
- 接客完了、接客評価、個々の行動のどれを加算条件にするか。
- 行動分類別熟練度を初回から保存するか、後続で追加するか。
- 体力消費、疲労、報酬への暫定効果量。
- 特性と成長効果が重なる場合の計算順序。
- 自動交流方策が熟練度を参照するか、結果への補正だけに使うか。
