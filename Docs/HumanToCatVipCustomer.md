# 人気最終段階で解放するVIP客

更新日：2026-09-29 / 状態：初回実装済み

## 目的

人気目標を最後まで達成した後の継続営業に、それまでに覚えた配置と交流成果を組み合わせる高難度客を追加する。ゲームクリアそのものは最終目標の達成時に成立し、VIP客はクリア後に挑戦できる追加内容とする。

## 解放と来店

- 新規の「人気3段階」で最終段階をクリアすると解放する。
- クリア当日には追加せず、結果を確認して継続営業を選んだ翌営業日から毎日1名、tick 0に来店する。
- 解放後に人気が下がっても解放状態を維持する。
- 休業日はほかのお客さんと同じく来店しない。
- 旧セーブや人気以外の目標には後付けしない。

## 公開条件と報酬

顧客名簿に最初から未解放のVIP客を表示し、次の条件を公開する。

1. 特徴「三毛」の猫を担当にする。
2. 「心をつかむ」を1回以上発動する。
3. 「心を開く」を1回以上発動する。
4. 両方の特別行動を同じ手番で1回以上発動する。

すべて満たした場合は通常の会計と接客評価に加えて、追加料金400と人気10を得る。条件未達時は追加料金と追加人気を得られず、接客評価へ未達を反映する。お詫び費用は設けない。

自動割り当てでは、担当可能な三毛猫がいれば体力より優先する。交流中の特別行動条件は、割り当て後も自動交流方策が通常どおり判断する。

数値は全体の流れを確認するための暫定値であり、細かなバランス調整は後回しにする。

## 表示・保存

- 顧客名簿に解放条件、報酬、解放日、直近の条件別結果を表示する。
- 営業ログに解放と接客結果を表示する。
- 解放日は人気目標の保存済み履歴から導出し、保存再開や結果画面の再閲覧で解放・報酬を重複させない。
- 詳細リプレイでも初期設定、解放、来店、接客結果を再現する。

## 初回確認範囲

解放前後の来店、複合条件の達成・未達、追加料金と人気、名簿、保存再開、詳細リプレイ、破損データ、VIP設定のない旧セーブを確認する。
