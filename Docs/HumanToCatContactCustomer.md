# 触れ合い好きのお客さん

更新日：2026-09-30

新規の人気3段階モードに追加するお客さん。人気第1段階を達成すると解放され、翌日以降の日曜日の営業開始時に1名来店する。休業日は来店しない。他モードには追加しない。

## 接客条件と報酬

お手入れブラシを設置した席で、通常の「なでる」「ブラッシング」を合計3回以上行うと達成。追加料金160と追加人気3を得る。切り替え、休憩、特別な交流は回数に含めない。設備なし・別設備・回数不足・未接客では追加報酬を得ない。満足評価にも条件の達成／未達を反映する。

自動割り当ては空いているお手入れブラシの席を優先し、自動交流は触れ合いを優先する。名簿に解放状態、来店曜日、条件、直近の判定を表示し、接客終了時には条件判定と報酬をイベント表示する。

## 保存と互換性

設定は `config/cafe_contact_customer.json` から新規ゲーム開始時に読み、`contact_customer` として固定する。条件判定には接客終了時に記録した設備と通常行動の回数を使い、後日の設備移動で過去結果は変わらない。保存・読み込み・詳細リプレイに対応し、保存失敗後の再試行でも報酬を重複させない。

既存セーブと旧ログには自動追加しない。遊び客の火・木・土、静かな交流客の月・水・金という既存設定、および旧静かな交流客の毎日来店は維持する。接客設定の新しいフラグは対象客にだけ保存する。

## 実装と検証

中心は `cat_cafe_sim/core/cafe_contact_customer.py`。`tests/test_cafe_contact_customer.py` の12件で日曜来店、解放・休業、通常行動計数、設備条件、会計・人気、自動接客、保存失敗、旧セーブ・他モード、設定固定・不正データ、リプレイ、名簿GUIを確認する。
