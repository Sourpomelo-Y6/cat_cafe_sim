# 猫の加入経路と後続計画

更新日：2026-09-30 / 状態：受け入れ・依頼・購入・派遣紹介を実装済み

加入方法の現行範囲と将来候補を区別します。ユーザー提示の4経路、スカウトの案、会話中の追加提案は[整理前の記録](History/2026-09-30/HumanToCatRecruitmentPlan.md)に保存しています。

## 実装済みの加入経路

| 経路 | 現行範囲 | 仕様 |
| --- | --- | --- |
| 保護猫の受け入れ | 初回3匹、3日ごとに3候補追加、費用200。紹介元12種類を巡回し、提示済み候補を保持 | [受け入れ](HumanToCatRecruitment.md) |
| 固定日の依頼 | 新規ゲーム4日目に一度、猫と費用を見て受け入れ／見送り | [依頼](HumanToCatIntakeRequest.md) |
| ペットショップ | 新規ゲームの固定3匹、価格400・450・500、各1回、補充なし | [購入](HumanToCatPetShop.md) |
| 派遣先からの紹介 | 新規ゲームの商店街から帰還し報酬を受領後、準備中に費用200で迎える／見送る | [紹介](HumanToCatDispatchIntroduction.md) |

猫の所属登録・関係登録・費用・加入履歴を保存し、加入後は出勤・休養・派遣・プレイヤー交流へ接続します。対象条件・保存失敗時の再試行・候補の固定は経路ごとの仕様を参照してください。

## 飼育枠と互換性

新規ゲームは在籍6匹までで、費用500により9匹へ拡張できます。派遣中・家出中も在籍数に含めます。旧セーブは上限なしの従来ルールを保持します。[飼育スペース](HumanToCatHousing.md)を参照してください。

加入はプレイヤーが選び、候補の発生だけで自動加入させません。候補の個性・特徴・特性、費用・飼育枠・残金を迎える前に確認します。旧セーブへの適用は経路ごとに異なり、ペットショップ・派遣紹介は後付けしません。

子猫は外部へ預ける費用だけを扱い、所属・育成・活動の対象にせず、6匹目標にも数えません。起動時の参加猫選択やテスト猫追加は、経営中の加入経路とは別です。

## 後続候補と優先度

| 候補 | 内容と未決定事項 |
| --- | --- |
| 野良猫スカウト | ユーザー指定で低優先度。場所への反復訪問と交流で慣れる案。出現条件・時間消費・失敗時の扱い・訪問省略は未決定 |
| 他のイベント加入 | 常連の相談など、現在の依頼・派遣紹介以外の条件と候補 |
| 店に通う猫 | 店先で何日か交流して加入を選ぶ案。交流と出現条件は未決定 |
| 一時預かり | 相性や特性を知って正式に迎える案。所属、活動、返却、費用、目標算入を別途定める |

スカウトを加入や6匹クリアの必須経路にしません。共通加入処理を再利用できる範囲で拡張し、実装順は[実装予定](HumanToCatPlannedFeatures.md)とユーザーの依頼に従います。
