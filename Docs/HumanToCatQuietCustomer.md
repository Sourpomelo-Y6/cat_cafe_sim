# 静かに過ごしたいお客さん

更新日：2026-09-30 / 状態：初回実装済み

## 解放と来店

新規の「人気3段階」で人気第1段階を達成すると解放する。達成当日の追加来店はなく、翌営業日から1日1名、開店時に来店する。顧客IDは `advanced-quiet` で固定し、親しみ・来店回数・常連度・不満を通常の顧客記録へ接続する。

第2段階への挑戦・自由営業への継続・人気低下後も解放を維持する。休業日は来店しない。既存の曜日予定、店舗イベントによる予定変更、累積不満による停止、永久離脱を適用する。旧セーブ・旧リプレイと、有力者・好感度・自由営業で開始したゲームへは後付けしない。

## 条件と報酬

| 項目 | 初回仕様 |
| --- | --- |
| 必要な席設備 | 静かな交流スペース（`quiet_space`、購入費450） |
| 必要な交流 | 声かけ・そばにいるの通常行動を合計3回以上 |
| 達成時 | 追加料金150・人気3（暫定） |
| 条件未達 | 追加料金・追加人気0。通常の会計を維持 |

担当猫の毛色・柄を必須条件にしない。猫の特徴に対する通常の好みは開始シードから決まり、未来店の名簿でも確認できる。通常行動4種を回数へ含め、分類の切り替え、休む、心をつかむなどの特別行動は含めない。関心上昇の量や反応によらず、実際に行った通常行動の回数を評価する。

設備と回数の両条件を接客終了時に判定し、時間料金、特別行動ボーナス、満足評価による追加料金へ重ねて加算する。条件達成・未達は満足評価へそれぞれ＋1・−1として反映し、満足評価から常連度・不満へつなぐ。独立した罰金は追加しない。追加人気は閉店時に既存の人気獲得へ加算し、人気上限も適用する。

手動切り上げ・閉店・体力切れも終了までの実績で判定する。未接客で退店した場合は報酬0で、通常の未接客評価だけを適用する。

## 操作と自動接客

「準備・お店」→「お客さんの名簿・来店予定…」で、解放前から条件・報酬と当日／翌日の来店予定を確認できる。接客済みの場合は直近の設備一致・交流回数・達成／未達・追加料金・人気も表示する。営業ログへ解放と結果を残す。

手動割り当てでは設備のある席と担当猫を選ぶ。自動割り当ては、この客を割り当てる時点で空いている静かな交流スペースの席を優先し、対象席が空いていなければ通常の空席を使う。待機列の順序を変更したり、接客中の客を移したりはしない。

この客の自動交流は、猫の得意分類より静かな交流を優先する。猫の個性に合わせた交流種類の選定、特別行動・体力への対応、同じ分類を2回続けた後に別分類を挟む既存の方策を使う。通常客の方策と熟練・設備効果は従来どおりで、静かな交流を優先することによる追加倍率は設けない。

## 保存と互換性

`config/cafe_quiet_customer.json` の条件・報酬を新規開始時に `quiet_customer` として固定し、保存再開時は設定ファイルを読み直さない。解放日は保存した人気目標の履歴から導出する。

対象客の接客設定だけに `quiet_service: true` を保存し、成果に接客開始時の対象設備の有無 `quiet_equipment` を残す。静かな交流回数は従来の `type_actions` から導出する。通常客・旧ログにはこれらの項目を加えない。設備を翌日に取り外しても過去の判定は変わらない。

1席・複数席の接客途中、会計後、翌日の保存再開と詳細リプレイに対応する。保存失敗時も会計済みの料金と判定を保持し、再試行で再付与しない。読み込み時にルール、来店、接客設定、料金・人気の日次記録を照合する。
