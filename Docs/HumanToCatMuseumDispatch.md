# 小さな美術館への派遣

更新日：2026-10-01 / 状態：実装済み。数値は暫定。

マイペースの猫を店内接客と派遣のどちらに配置するか選ぶ派遣先です。新規ゲームの全モードに開始時設定を保存します。

## 解放と参加

| 項目 | 仕様 |
| --- | --- |
| ID / 名前 | `small_art_museum` / 小さな美術館 |
| 解放 | 人気第２段階を達成 |
| 必要特性 | マイペース（保存済みID `easygoing`） |
| 疲労上限 | 40以下（40も参加可能） |
| 期間 / 基本報酬 | ２日 / 350 |

人気の数値だけでは解放せず、第１段階の達成も対象外です。派遣報酬の受取回数は条件にしません。第２段階達成の閉店時に解放を記録し、結果確認と翌日の準備から出発できます。一度解放した後は人気が下がっても維持します。

人気モード以外は、途中から[人気挑戦](HumanToCatObjectiveSelection.md)を開始して第２段階を達成すれば解放できます。準備中・在店・健康・担当可能・席数を超える余剰猫が必要で、未解決イベント・未保存結果・同じ猫の二重配置・進行終了後の制限は[派遣共通仕様](HumanToCatCafeActivities.md)に従います。通常の初期猫の割り当ては維持し、６回目の保護猫紹介のシオンから参加できます。

## 専用イベント

出発時に `museum_visitor_request`「来館者との交流をお願いされました」を一件固定し、１日目の閉店または休業で発生します。この派遣先だけに適用し、回答まで次の進行を止めます。

| 選択 | 帰還報酬の増減 | 回答時の疲労 | 回答時のストレス |
| --- | ---: | ---: | ---: |
| 来館者との交流を引き受ける | ＋100 | ＋10 | ＋10 |
| 交流を見送って予定どおり終える | 0 | 0 | 0 |

負担は回答時の固定加算で、マイペースの接客ストレス0.75倍は掛けません。既存の上限・下限に収め、派遣中に在店休養の回復を適用しません。期間は両選択とも２日のままです。

追加報酬は回答時に入金せず、特性・成長補正済み基本報酬に加えて帰還受取時に精算します。通常は引き受け450／見送り350、派遣得意なら485／385です。資金と日次の派遣収入、派遣経験へ反映します。マイペースの帰還追加ストレスは0です。帰還時にブラッシングセット１個を受け取れます。両選択で同じ１個です。歓迎条件・猫紹介・家出トラブルは設けません。

## 表示・保存互換

派遣一覧・比較に解放理由と参加条件、両選択の報酬・負担を表示します。出発確認で出来事を予告し、回答・帰還内訳・解放ログは共通画面へ接続します。閲覧や取消は状態を変えません。

[派遣解放設定](../config/cafe_dispatch_unlocks.json)の任意項目 `dispatch_unlocks.rules.small_art_museum` に `stage: 2` と派遣先を新規開始時に固定します。既存の人気・受取回数条件と共存し、他の派遣先の条件は維持します。解放日は第２段階達成日以降で検証します。[イベント設定](../config/cafe_dispatch_encounters.json)は出発時に既存の `encounter` と詳細ログへ固定します。

設定がない旧セーブへ派遣先を後付けせず、既存の出発済み派遣・候補・旧ログを維持します。新規開始時設定があるゲームは後から人気挑戦できます。保存形式は営業セーブ2・チェックポイント1・詳細リプレイ4を維持します。保存再開と詳細リプレイでは保存した設定を使い、解放条件やイベントを現在の設定から読み直しません。同じ回答・帰還受取・保存失敗後の再試行で負担や報酬を二重処理しません。

## 検証

[追加テスト](../tests/test_cafe_museum_dispatch.py)で全モードの第２段階解放、数値だけでは未解放、受取0回の解放と維持、特性・疲労境界・健康・余剰猫、事前比較と確認取消、両選択と営業・休業、回答待ち進行制限、資金・収支・上下限、二重回答・受取、旧セーブ・設定固定・保存失敗後の再試行、不正な解放日・派遣記録、６回目の保護猫加入からの実派遣を確認します。GUIでは解放表示、出発予告、回答効果、帰還内訳と最小画面の操作を確認します。

検証結果：追加７件成功（GUIを含む21.218秒）、GUIを含む全1050件成功（266.332秒）。ローカルリンクと差分チェックも成功しました。


## ブラッシングセット報酬（2026-10-01）

更新後に新しく出発する美術館派遣は、[報酬設定](../config/cafe_item_rewards.json)の `brushing_set`（ブラッシングセット、ストレス回復20）を１個固定します。両選択で個数・効果は同じです。特性や成長による資金倍率を用品に掛けません。資金報酬・期間・選択時の負担は維持します。

派遣中・回答後・帰還待ちには在庫へ入れず、帰還報酬受取で一度だけ所持品へ加えます。受取後は[所持品・ケア](HumanToCatItems.md)から営業準備中の在店猫に使用し、ストレスを固定20回復（下限0）。ストレス0では消費しません。疲労・体力・好感度・病気・療養日数は変更しません。未使用品は暫定100で売却できます。購入対象には追加しません。

比較・出発確認・帰還内訳と所持品に名前・１個・回復効果を表示します。出発済みの報酬なし記録へ後付けせず、旧ゲームの派遣設定と旧ログは維持します。既存の `item_reward`、使用と売却の入手元IDを利用し、保存形式を維持。再開・詳細リプレイで現在の報酬設定を読み直さず、重複受取・使用・売却・保存失敗後の再試行で在庫や資金を増やしません。

[報酬の追加テスト](../tests/test_cafe_brushing_set.py)５件で両選択、受取前の拒否、１個入手、固定20回復と疲労維持、ストレス0の不消費、在店・経営条件、売却収支、設定固定・保存失敗再試行・二重消費防止、旧出発済み記録と他派遣先維持を確認します。GUIでは予告・帰還内訳・所持品と使用／売却ボタン・実際の使用を確認します。追加５件成功（GUIを含む9.321秒）。

ブラッシングセット報酬追加後の全体検証：GUIを含む全1055件成功（268.306秒）。関連資料のリンクと差分チェックも成功しました。
