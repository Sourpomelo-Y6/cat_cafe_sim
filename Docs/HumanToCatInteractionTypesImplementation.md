# 8種類の交流と猫の個性：版3の実装記録

2026-09-12追記：[交流の目的・終了・成果の見直し](HumanToCatInteractionPurpose.md)を整理した。
本書の「成功」は旧来の暫定的な両側特別行動の発動条件を指し、好感度や交流全体の良さを意味しない。
低体力からの達成は必須要件ではない。版3のルールは維持し、終了と成果の分離は[版4](HumanToCatRelationshipImplementation.md)で実装した。


更新日：2026-09-11 / 単独交流ルール版：3

[暫定仕様](HumanToCatInteractionTypes.md)に沿って、8種類の交流、種類・強さの好み、
飽きやすさ、切り替え親和度を実装した。特別行動は版2の処理を共有する。
種類定義と個性を別の設定項目にし、比較後も暫定値を変更していない。

## 起動と画面操作

```bash
# 版3を指定（現在の既定は版4）
python3 -m cat_cafe_sim.human_cat_gui --rules 3
# 旧版の画面
python3 -m cat_cafe_sim.human_cat_gui --rules 2
python3 -m cat_cafe_sim.human_cat_gui --rules 1
```

変更先の選択欄は「遊ぶ」「触れ合う」「静かに過ごす」で分類した8種類を表示する。
選択だけでは状態は変わらず、「動作を切り替える」ボタンで1ターン進めて変更する。
現在と同じ変更先や強制connect予約中は変更ボタンを無効にする。
有効な動作は現在の種類によって変わり、履歴には種類名も日本語で表示する。

次の交流の条件欄で5個性プリセットを選べる。「個性の詳細…」では8種類の好み、
3つの強さの好み、飽きやすさ、切り替えの好みを編集できる。
詳細画面で保存しても現在の交流は変わらず、「この条件で再開始」で適用する。
キャンセルでは編集を破棄する。不正値の場合は現在の交流と確定済みの次回個性を保持する。
再開始で履歴・ゲージ・資金を初期化するため、残したい交流は先にログ保存する。

## 設定・CLI

- `config/human_cat_types.json`：通常／特別行動ルール、8種類の定義、既定個性。
- `config/cat_personalities.json`：中立、活発な探検家、穏やかな甘えん坊、距離を大切にする猫、遊び好きで繊細な猫。

```bash
python3 -m cat_cafe_sim.human_cat_demo run --rules 3 \
  --preset '穏やかな甘えん坊' --actions direct switch:pet direct pause adapt
python3 -m cat_cafe_sim.human_cat_demo replay reports/human_cat_types_session.json
python3 -m cat_cafe_sim.human_cat_demo compare --rules 3
```

CLIの既定版は従来どおり1。版3は明示する。`switch:ball`のように変更先IDを指定する。
APIでは`TypesInteraction.step('switch', target_type='ball')`。
変更先なし・不明ID・現在種類への変更・switch以外への変更先指定は、時間も履歴も進めず拒否する。

`--config`で種類定義と個性を含む別設定、`--preset`でその個性だけをプリセットに置き換えられる。
`--stamina`、`--tension`、`--engagement`による診断用の開始値指定も利用可能。
版3の既定ログ名は`human_cat_types_session.json`。旧版の既定出力は上書きしない。

## 処理と互換性

通常の状態更新と特別行動を版1／2と共有し、版3は種類に応じた効果計算と変更先指定を担当する。
同じ遊び分類内の種類変更では飽きが継続する。交流せず別分類を往復しても履歴を消さない。
猫の個性は公開観測には含めず、種類・強さ・飽き・切り替えの補正は診断ログに記録する。

種類リストは8つの既知IDを必須とし、欠落・重複・不明IDを拒否する。
個性にも全IDと全強さを要求し、従来の2要素preferencesは版3へ暗黙補完しない。
設定JSONとプリセットJSONの重複キー、非有限値、範囲外、必須動作の欠落も検証する。
版3の設定・ログは種類定義と個性のスナップショットを保存する。
旧版のログは版に応じたcoreで再生し、既存学習モデルを版3に転用しない。

## 比較結果

5個性×開始体力100／20×12方策の120条件を実行した。
12方策は8種類それぞれを固定する方策、分類内変更、分類間変更、反応に応じた変更、停止のみ。
どの方策も強制予約を優先し、停止方策以外は任意資格があればconnect、体力20以下なら停止する。
固定種類方策も開始はねこじゃらしで、他種類の場合は最初に変更の1tickを使う。

| 個性 | 成功 / 24 | 時間切れ / 24 | 平均資金 | 平均体力消費 |
|---|---:|---:|---:|---:|
| 中立 | 1 | 23 | 10.42 | 42.90 |
| 活発な探検家 | 5 | 19 | 43.75 | 36.83 |
| 穏やかな甘えん坊 | 5 | 19 | 39.58 | 38.77 |
| 距離を大切にする猫 | 0 | 24 | 4.17 | 43.52 |
| 遊び好きで繊細な猫 | 7 | 17 | 62.50 | 34.31 |

開始体力100の固定種類比較では、活発な探検家はねこじゃらし・ボール・トンネルで資金200を獲得。
甘えん坊はなでる・ブラッシングで200、繊細な猫は4つの遊び種類で200だった。
この比較の通常動作はdirectであり、繊細な猫が激しい動作を好むという結果ではない。
仕様の強さの違いは別の手計算テストで検証した。

分類内変更は10条件中1成功・平均資金25、分類間変更は4成功・85、反応に応じた変更は3成功・60。
分類間変更の有利さが見えるが、選ぶ種類も異なるため、飽きリセットだけの因果効果とは断定しない。
停止のみは全条件で資金0。開始体力20での成功は全60条件中1件だった。
距離を大切にする猫の達成可能性や低体力条件は、追加の方策診断・試遊の課題として残る。

関心は特別行動で消費するので、終了時の関心だけで方策や個性を順位付けしない。
今回の固定方策では低消費の静かな交流だけが全猫で有利になる結果は見られなかったが、最適性は未検証。
特定プリセットが成功しやすいこと自体をバランス調整完了とは扱わない。

レポートは`reports/human_cat_types_comparison.json`と`.md`、120件のログは同名ディレクトリ。
関心・テンション・資金・体力消費・終了理由・同時発動数・種類ごとの交流回数を保存する。
これらは決定的な仕様診断であり、学習の未使用評価ではない。生成物は従来どおりGit管理外。
