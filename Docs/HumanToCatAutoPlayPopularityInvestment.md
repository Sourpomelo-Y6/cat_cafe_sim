# 人気向け積極経営の待合投資と比較

更新日：2026-10-03。人気目標の積極経営（`fast`）に待合スペースの購入・2段階目の強化を追加した。通常操作で待機枠と待機猶予を広げ、列満員の退店を減らす。達成日短縮の効果は小さく、安定経営より速いことや無発症を保証する方針ではない。

## 調査と採用した判断

変更前のシード0では、12日目の増席前に出勤候補2匹・健康な担当可能猫5匹と予測し、4席目を購入していた。増席後の負担予測では実際の出勤が1匹となり、9人中2人を接客、7人が待機期限切れとなった。27日目には出勤候補1匹でも5席目を購入し、その日は休業した。在籍猫の総数に基づく先行増席だけでは、休養で少なくなる出勤猫を補えない。

予備試行では、増席を当日の出勤候補数に合わせるだけの案はシード0で37→42日となった。おもちゃをクッションへ替える案は31日目・人気445で第2段階の期限切れとなった。両案は不採用。席を増やす判断・既設の接客設備は維持し、まだ自動購入していなかった待合設備を使う。

人気向け積極経営は、営業準備中に次の条件を確認する。

- 保存済みの待合機能があり、当日を含む段階期限まで残り2日以上。
- 今日の来店予定が「既存席数と出勤候補数の小さい方」を上回る、または前日の結果に待機期限切れ・列満員退店がある。
- 通常の解放条件を満たす。初回は人気第1段階後、2段階目は第2段階後。購入済みの設備を重複購入しない。
- 購入後に最低300、または1席増設した場合の運営費と購入後の待合維持費の2日分のうち大きい方を残す。

休養スペースの初回購入を最優先し、次に上記の待合投資を判定する。条件を満たさない場合は、従来の増席・休養設備強化・おもちゃ・防音改修・出勤判断へ進む。待合購入後のほかの投資にも、待合維持費を含む予備資金を使う。資金不足なら待合のために営業やほかの投資を止めない。

初回は保存済みの待合設定を使う。標準設定では費用800・維持費10/日・待機枠＋1・猶予＋2刻み。2段階目は通常の強化設定で費用1,200・維持費20/日・待機枠＋2・猶予＋4刻み（初期設定からの増加）。ゲームの価格・効果・人気条件・料金・健康係数・出勤上限は変更しない。

安定経営・基礎営業・好感度向けの投資判断は維持する。有力者向けは従来の専用準備を使う。待合機能のない旧セーブに機能を後付けせず、通常の準備へ進む。営業セーブ2・チェックポイント1・詳細リプレイ4を維持し、更新後の判断は保存済み状態から決める。席数上限は8席、最終人気達成で停止する通し自動プレイの増設は通常5席まで。

CLI・GUIは同じ判断を使う。日本語ログとGUI判断一覧に、待合購入の理由、来店予定・出勤候補、前日の取りこぼし、購入費・維持費・予備資金を表示する。最大10日のGUIおまかせ、目標結果での停止、中止・保存再開を維持する。

## 同じ10シードの結果

[変更前の共通人気評価](Results/AutoPlayPopularityPolicyEvaluation.json)と[変更後の20試行](Results/AutoPlayPopularityInvestmentEvaluation.json)を比較する。通常の新規人気ゲーム、シード0〜9、安定／積極経営、最大60日。店舗イベント・猫・客の設定は通常のまま。変更前は最大90日の記録だが、全試行43日以内に達成しており、どちらも上限停止はない。初期条件のハッシュは一致する。

安定経営の10件は、変更前と終了理由・全期間の指標・段階結果・操作数・目標成果・現在日・保存確認がすべて一致した。共通期間の指標は相手の終了日が変わるため再集計される。変更後の全20件で、達成・最終保存読込の状態一致・収支一致を確認した。

積極経営の列満員退店は合計100→20件となった。待機期限切れ率は少し改善したが、件数は増えており、待ち客の問題が解消したわけではない。終了資金は平均2,194減る。発症は変更前のシード2・5・8で各1回から、変更後のシード6で2回・9で1回へ移った。無発症の改善ではない。
