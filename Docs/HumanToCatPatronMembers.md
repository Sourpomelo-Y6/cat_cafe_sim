# 3人の有力者と条件による満足度

更新日：2026-10-03。ユーザーの希望に沿い、従来の地域の有力者に、気分型・厳格型の2人を追加した。新規の有力者目標は3人全員の達成を要件とする。期限は設けない。旧セーブ・旧ログは保存済みの一人の目標を維持し、新しい2人を後付けしない。

## 相手と加点

| 相手 | 目標 | 条件と満足度 |
| --- | ---: | --- |
| 地域の有力者 | 100 | 従来どおり基本＋25、白猫・接客の得意分野で歓迎加点 |
| 気分が変わる有力者 | 100 | 現在の希望に一致＋20、不一致＋2 |
| 条件に厳格な有力者 | 100 | 白猫かつ接客の得意分野で＋25、それ以外＋0 |

厳格型の一致時＋25は初版の仮値。気分型の希望は「白猫 → 黒猫 → 長毛 → 白猫…」と帰還を受け取るたびに切り替わる。乱数ではなく固定の巡回で、同じ保存データ・ログでは同じ希望になる。将来のランダム化は未採用。達成した後の継続訪問でも希望は次へ進む。

各訪問は2日・基本報酬200・疲労40以下で、既存の健康・体力・席数を超える担当可能猫数の条件を使う。追加2人の希望は満足度だけに影響し、条件不足でも基本の派遣報酬は得られる。条件不足でも派遣できるが、派遣前の猫一覧・確認画面・比較画面に「満足度＋2」「満足度＋0」を表示する。厳格型の白猫と接客の得意分野は両方必要で、片方だけでは加点しない。初期の白猫や受け入れ候補を育成して対応できる。

追加の各相手に対して、訪問は同時に1件まで。同じ相手への同日2回の出発はできず、帰還確認後に出発可能な次の準備から新しい訪問を始める。別の相手へは、通常の余剰猫条件が満たせれば同時派遣できる。従来の地域の有力者の派遣制限は変更しない。

希望の判定は出発時に固定する。訪問中に気分・得意分野などが変化しても、出発時の判定と見込み満足度を使う。帰還待ちではまだ満足度・次の希望を更新せず、帰還を受け取った時に一度だけ加点する。目標値を超える分は切り捨て、同じ帰還の再確認では二重加点しない。

## 画面と目標

有力者の目標画面に3人それぞれの進捗・加点条件を表示する。派遣先には3人の訪問先を並べ、現在の希望と猫ごとの判定を確認できる。派遣結果には出発時の希望・条件判定・満足度の加点見込みを残す。

一人を達成しても全体の目標は未達のまま。全員を達成した時に結果確認待ちとなり、継続営業できる。全体の成果欄は目標合計300・達成値300を記録する。各人の内訳は有力者画面に残す。人気への途中挑戦とは独立し、人気の開始・期限切れ・結果確認で3人の進捗を消さない。

## 保存と互換性

特徴・育成の仕組みがない旧営業で新しく目標を有効にする場合も、一人の従来設定を使い、達成できない条件を後付けしない。

既存の有力者設定と主たる満足度の項目は維持する。新規開始・新しく目標を有効にする時だけ、[追加設定](../config/cafe_patron_members.json)を保存済みルールの任意項目 `members` に追加し、相手別の満足度を持つ。既存の任意機能・セーブ・チェックポイント・詳細ログの形式番号は変更しない。

追加の訪問には出発時の希望・希望番号・一致判定・予定加点を保存する。復元時は保存済みの設定、出発日と帰還履歴、猫の特徴と当時の得意分野から判定を検証し、条件・加点・満足度・全員の達成日・成果の不整合を拒否する。新しい設定ファイルは再開時に読み直さない。地域の有力者だけの旧セーブは従来の目標値・加点・派遣・成果・ログ再生を維持する。

## 自動プレイ確認

目標検証CLIの `--objective patron --mode clear` は、未達の相手へ1件ずつ訪問する。候補の中から予定加点の高い猫を優先し、同点なら疲労・IDで選ぶ。厳格型に加点できる候補がいない日は営業と育成を続ける。気分型は一致する候補が派遣できない場合、不一致＋2で進めることもある。基礎営業は新しく派遣しない方針のまま。安定・積極経営の有力者経路は共通で、複数派遣や最速化は今回行わない。

通常条件・シード0・初期5匹2席・最大90日・安定経営で、全員の満足度100を45日目に達成した。完了した日数45日、1,760操作、終了資金38,910。地域4回・気分型14回・厳格型4回の計22回の訪問。気分型は一致4回（＋20）・不一致10回（＋2）、厳格型は一致4回（＋25）だった。気分型の不一致による低加点が実際に進行日数へ反映されている。

[設定・進捗・訪問ごとの固定判定・結果JSON](Results/AutoPlayPatronMembersEvaluation.json)を保存した。最終状態の保存再開と詳細リプレイが元のスナップショットと一致した。これは初回の達成経路の確認であり、手動プレイの楽しさ・最速日数・全条件の達成を示すものではない。その後の[10シード評価](HumanToCatPatronMembersSeedEvaluation.md)では全員達成10/10、平均58.0日を確認したが、発症・家出の多さを課題として記録した。仮値のさらなる調整は保留する。

```bash
python3 -m cat_cafe_sim.cafe_autoplay --objective patron --mode clear --days 90 --directory reports/autoplay_patron_members
```
