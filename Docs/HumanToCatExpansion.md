# 店の増設：2席から3席へ

更新日：2026-09-22 / 状態：初回実装済み

営業で得た資金を店の拡張に使い、接客・派遣・休養の割り振りにつなげる。
初回は2席から3席への一度だけの増設。費用は暫定500で、細かな調整は後回しにする。

## 操作・条件

1. 営業準備中に営業画面の「店の増設・設備…」を開く。
2. 現在の席数、2席→3席、費用、支払い後の所持金を確認する。
3. 「3席に増設する」を押し、確認すると即座に3席になる。

- 支払い後に資金が残る場合のみ購入可能。資金500以下では購入できない。
- 一度だけ購入でき、重複購入・4席以上への増設・売却・返金はない。
- 確認のキャンセルや画面の閲覧では、席数・資金を変更しない。
- 準備中だけ購入可能。営業中・閉店後・交流結果の保存待ち・プレイヤー交流中・帰還等のイベント待ち・目標結果待ち・ゲームオーバー中は不可。
- 経営ルールの導入は必須ではない。資金に関する条件は導入の有無によらず適用する。
- 新規ゲームは引き続き2席から開始する。既存の2席セーブも準備中に購入可能。
- 1席の検証用営業からの増設は初回範囲に含めない。

設定は [cafe_expansion.json](../config/cafe_expansion.json)。増設済みの画面には購入日と実際の支払額を表示する。

## 接客・派遣・一日の流れ

増設した `seat-3` はその日の営業から使用できる。手動配置の席選択にも、自動配置の空席候補にも加える。
3席の交流は同じ営業時計で進み、同じ猫・お客さんを複数の席へ割り当てることはできない。
接客コマンドは引き続き自動で選ぶ。

来客数・出勤予定・猫の人数は増設によって自動変更しない。担当できる猫が3匹未満なら空席が残る。
派遣は現在の店内席数を基準に判定するため、増設後は担当可能な在店猫が3匹を超える場合だけ新たに派遣できる。
既に派遣中の猫はそのまま派遣を続け、増設によって取り消し・即時帰還しない。
休養・休業・翌日進行でも席数は3席のまま維持する。

## 会計と保存

増設費用は購入日に一度だけ差し引き、接客売上とは別の支出として扱う。
「営業結果を比較…」に、その日の席数と増設費用を表示する。過去の2席営業の日は書き換えない。
休業日に購入した場合も同日の支出。以後の日には費用0を表示する。

営業セーブ形式2・チェックポイント1に任意の `expansion`（購入日・支払額）を追加し、現在の席数3と席ごとの状態を保存する。
読み込み時は席数・増設記録・日次履歴・所持金の整合性を照合する。3席なのに増設記録がないデータは拒否する。
購入直後・3席の交流途中・閉店後・翌日で保存再開でき、再開だけで再課金しない。
保存失敗時も起動中の増設結果を保持し、保存を再試行する。購入をやり直さない。

リプレイ4に `expand_seats` 操作を追加する。起点なしの3席ログは2席から開始し、購入操作を再現する。
3席のチェックポイントを起点とするログでは購入済み状態から再開する。
旧1席・2席のセーブとログは従来どおり読み込む。3席への対応を旧版プログラムに戻して読むことは保証しない。
