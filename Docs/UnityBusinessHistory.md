# Unity 営業成果・日次比較

メニューの「営業成果・日次比較：人気・評価・離店」から、閉店した日の営業成果を確認できます。既存の収支履歴と画面を共用します。収支の入口から開くと従来の収支内訳、営業成果の入口から開くと経営指標を表示します。

## 表示と比較

店の人気、獲得人気、交流件数、接客評価（満足・普通・不満）、満員で帰った客、待ち切れず帰った客、目標結果、席数、店舗イベントを日別に表示します。「前の記録」「次の記録」で営業日・休業日を切り替えます。前日差は人気・獲得人気・交流件数・評価件数・離店件数について表示します。獲得人気はその日に得た値で、店の人気の前日差とは異なります。

Python既存の `comparison_rows` と確定済みの営業結果を読み取ります。現在閉店している日は含み、営業途中の日は含めません。直前の日付の確定記録がない場合は「比較できる記録なし」、未導入や値がない場合は「未導入・記録なし」と表示します。現在値で過去を埋めません。離店理由の件数は既存Python画面と同じく、理由の記録がない場合は0件です。

## 保存・操作条件

閲覧は読み取り専用です。ゲームの設定・報酬・資金・乱数・営業履歴を変更せず、保存形式は既存のままです。保存・再開後も同じ日次記録を閲覧できます。状態の再取得で選択日を保持し、別ゲーム読込では画面と選択を初期化します。未接続では最後の記録であることを表示し、日付移動を停止します。画面は閉じられます。

## 確認

- 追加の営業成果テスト3件と既存の収支履歴テスト3件が成功。
- 営業中の日を除外、閉店日を1回だけ表示、休業日、前日差の正負、日付の欠落、旧記録、読み取りによる状態非変更を確認。
- HTTPで保存・翌日・再読込後の同一履歴と元ファイルの非変更を確認。
- Unityでメニュー16項目、記録なし、日付移動、選択保持、未接続、従来収支モード、別ゲーム読込を確認。
- Unity Playモードの実メニュー・前後ボタン、保存・HTTP再開後の同一表示を確認。画面を撮影して配置を確認。
