# 閉店結果と翌日の営業

更新日：2026-09-14

通常の人対猫営業に、閉店結果の確認と翌日への進行を追加した。
従来の1日営業CLIと、単独交流のルールは変更しない。

## 操作と成果

閉店後、画面下部の「閉店結果・翌日へ」を押す。
当日の売上（ボーナス込み）、ボーナス内訳、累積所持金、猫ごとの残り体力と開始時からの消耗、猫とお客の組み合わせごとの親しみ増減を表示する。
親しみの変化は当日に確定した交流の実増減の合計で、上限・下限適用後の値。
確認画面で「いいえ」を選べば閉店状態に留まり、結果を再確認できる。「はい」で翌日の準備へ進む。
翌日は必ず一時停止から始まり、担当猫の指定または営業再開で進行する。
未保存の交流結果がある場合は、保存を再試行してから翌日へ進む。

## 暫定ルール

- 日付は1日目、2日目という営業日番号。実際のカレンダーとは連動しない。
- 所持金と猫からお客への親しみを引き継ぐ。日次売上・ボーナス・接客時間・待機列・来店状態はリセットする。
- 一晩で全猫の体力が上限まで回復する。健康な猫の体力切れによる担当不可を解除する。
- 精神力・疲労・健康状態・療養日数は変更しない。病気の猫は体力回復だけで担当可能にはならない。
- 営業時間・来店予定・参加猫・席数は前日と同じ。固定IDのguest-1等は同じお客として再来店し、前日までの来店経験と組み合わせごとの親しみを利用する。
- 初めて会う猫との組み合わせは初対面のまま。顧客名簿・新規客抽選・家賃・日次経費・長期的なクリア条件は未導入。

体力全回復は、毎日の担当選びを試せるようにするための暫定仕様。回復量による経営難度の調整は別途検討する。
当日の成果は売上・親しみ・消耗で評価し、一律の成功／失敗にはまとめない。

## 保存と再生

「営業を保存」で営業日・過去の日次結果・翌日の交流途中状態も保存できる。
翌日への移動そのものは自動保存しない。アプリ終了時の保存確認を利用する。
営業ログにnext_day操作を追加し、過去の交流結果も保持して全日程を再生する。
営業セーブ形式1、営業ログ形式1〜3を維持し、従来の単日ログ・セーブも読み込める。新しいnext_day操作を含むログは旧アプリでは再生できない。
関係保存の重複防止と古いセーブの検出は引き続き有効。詳細は[営業途中の保存と再開](HumanToCatCafeSaves.md)を参照。

ログは各操作の状態を記録するため、日数が増えるほど大きくなる。履歴の圧縮・長期運用向けの形式整理は今後の課題。
