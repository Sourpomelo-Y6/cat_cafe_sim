# Unity 出勤予測・休養案

営業準備の案内で猫を選ぶと、前日の接客行動数と閉店時の疲労・発症確率・ストレスの出勤/休養予測を確認できます。長い説明はスクロールして読めます。

## 計算と表示

Python既存の `shift_forecast` を状態APIで使用します。保存済み係数、特性、休養設備の効果を使い、状態・乱数・履歴を変更しません。前日記録なしと接客0行動、病気による出勤不可・残り療養日、派遣等の不在、未導入ルールを区別します。出勤予測は前日の接客量を基準にした目安です。

## 休養案

「休養案を作成」で健康な在店猫を疲労降順・同値はID順に最大2匹休養とし、残りの健康な在店猫を出勤にします。計算はPython既存の `fatigue_rest_schedule` を使います。

案の作成と手動編集はUnity内で行い、「案を確定」で既存の `set_shifts` に全体を1回送信します。取消・画面を閉じる操作で破棄します。日付・ゲーム・状態の版が変わった場合も古い案を破棄します。未確定中は営業開始・休業を止め、送信中・未接続・回答待ちも操作条件に従います。全員休養の案は確定後に「今日は休業する」を使えます。通常の猫ごとの出勤/休養操作は従来どおり即反映です。

## 確認

- Pythonの予測との一致、疲労同値時の順序、病気・不在の除外、記録なし・未導入表示、状態と元ファイルの非変更。
- HTTPでの一括確定・同一要求再送・保存再開。
- Unityで予測・案の手動編集・取消・閉じる・古い案の破棄・未接続・送信中の操作制限。
- Unity Playモードの実ボタンとHTTPで案の作成・変更・取消・確定、営業開始・自動進行・停止。
- 実画面のスクリーンショットで説明欄とボタンの配置を確認。
