# 気まぐれな長毛好きのお客さん

更新日：2026-10-01 / 状態：初回実装済み。数値は暫定。

新規の人気3段階モードに、確率で来店する新しい客種を追加します。ユーザー指定により、解放は**人気第2段階の達成**です。第1段階の達成では解放しません。既存客の解放条件・来店予定は維持します。

## 来店条件

第2段階を達成した翌日以降、営業日ごとに30％で1名、営業開始時に来店します。客IDは `advanced-longhair`。曜日の指定はなく、休業日は実際の来店を行いません。ゲームのseed・日付・この客種専用の識別子からSHA-256で来店判定を導出します。既存の乱数列を消費せず、他の確率処理の結果を変えません。

来店結果は日付ごとに固定です。同日の再表示・名簿閲覧・保存再開で変わらず、名簿では今日と翌日の予定を確認できます。確率は長期間での割合を保証する値ではなく、連続来店や不来店も起こります。実際に来店したときは既存の待機列・待ち時間・座席制限を使い、混雑時や閉店まで未接客なら追加報酬を得ません。

## 接客条件と報酬

| 条件 | 初回仕様 |
| --- | --- |
| 好み | 長毛。保存済み特徴ID `long_hair` で判定 |
| 達成条件 | 長毛猫との通常の触れ合いを3回以上 |
| 触れ合い | 通常の「なでる」「ブラッシング」各種の合計。切り替え・休憩・特別な交流は除外 |
| 設備 | 必須設備なし |
| 追加料金 | 120 |
| 追加人気 | 2 |

短毛猫や回数不足なら追加料金・追加人気は0です。通常の料金と接客結果の扱いは維持し、条件の達成／未達を満足評価にも反映します。既存の接客処理の触れ合い優先をこの客にも適用します。猫の自動割り当ては既存の好み一致・体力による選択を使い、長毛の好みを固定します。条件達成や接客完了を保証する機能ではありません。

名前・解放状態・来店確率・今日と翌日の予定・好み・接客条件・直近の判定を名簿に表示し、営業ログに解放と条件判定を表示します。追加料金は既存の会計・収支へ、追加人気は閉店時の人気集計へ一度だけ反映します。

## 保存と互換性

設定は [cafe_longhair_customer.json](../config/cafe_longhair_customer.json)。新規ゲーム開始時に任意項目 `longhair_customer` へ確率・必要回数・報酬を固定します。判定は保存済みのseed・日付・目標履歴・猫の特徴と接客結果の通常行動回数から行います。再開時に設定を読み直さず、追加の抽選操作や予測用の記録は保存しません。

旧セーブと旧ログへ自動追加しません。自由営業・好感度・有力者モードと、既存の途中開始の人気挑戦の追加客設定も維持します。この客種は新規の人気3段階モードへの導入です。営業セーブ・チェックポイント・詳細リプレイの形式番号を維持し、接客途中・精算後・第2段階の結果確認待ち・進行後に再開できます。保存失敗後の再試行で追加料金・人気を二重に反映しません。

この客にも既存の `contact_service` による触れ合い優先を使います。従来の触れ合い好き客の設備条件は維持し、長毛好き客の達成条件に設備判定を使いません。結果に残る `contact_equipment` は実際の席の既存記録で、長毛一致とは別に扱います。初期猫・加入候補の特徴を後付けしたり変更したりしません。
