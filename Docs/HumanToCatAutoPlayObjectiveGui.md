# GUIのおまかせ：人気・好感度・有力者

更新日：2026-10-03。営業画面の「10日間おまかせ…」を好感度・有力者モードでも利用できるようにした。ゲームの数値・交流枠・派遣条件・保存形式は変更せず、CLIと同じ `AutoPlayer` の判断と通常操作を使う。

## 使い方と対象

「目標」で人気・好感度・有力者のうち、現在のセーブに導入済みの目標を選ぶ。人気集計のみの設定は挑戦対象として表示せず、旧セーブへ新しい目標を後付けしない。人気への途中挑戦を開始済みなら、本来の目標と人気を切り替えて選べる。

初期選択はゲーム開始時の目標で、達成済みなどで挑戦できない場合は他の挑戦中の目標を選ぶ。目標がすべて終了している、未導入、結果確認待ち、経営終了、交流結果の保存待ちの場合は開始できない。派遣中やプレイヤー交流途中の保存データからも通常の状態で再開する。

「方針」は従来の基礎営業・安定経営・積極経営。方針や目標の選択はおまかせ画面内で保持し、セーブには追加しない。画面を開き直した際は基礎営業から始まり、再開時も希望の方針を選んで開始する。実行中は両方の選択を無効にする。

- 基礎営業は出勤・休養と必要な回答を行い、目標のための加入・交流・有力者派遣は増やさない。途中のプレイヤー交流は通常の終了操作で確定する共通処理を使う。
- 好感度の安定経営・積極経営は、通常の猫の受け入れとプレイヤー交流を行う。[安定経営は体力も評価](HumanToCatBondStaminaPlanning.md)し、積極経営は加点優先を維持する。
- 有力者の安定経営・積極経営は、通常の育成・派遣・帰還確認を行う。保存済みの一人の有力者も、新規設定の[3人の有力者](HumanToCatPatronMembers.md)も対応する。積極経営は[不足特徴の受け入れと希望一致の派遣待ち](HumanToCatAutoPlayPatronFast.md)を追加し、安定経営は従来の方針を使う。

## 実行内容の表示

進行欄に経過日数・ゲーム内の日目・選択した目標の進捗を表示する。好感度は達成した猫の数、有力者は保存済みの各人物の満足度、人気は現在値と必要量を表示する。

判断一覧と操作ログは従来のタブを使う。判断一覧には受け入れ・交流・派遣の判断も共通処理から表示し、行を選ぶと理由の全文を読める。同日・同じ対象の判断は従来どおり最新行に更新する。操作ログでは各交流行動・反応・種類切り替え・体力を日本語で確認でき、セット終了時に好感度の前後・残り体力・同時発動回数を表示する。有力者への訪問結果は対象の名前・満足度加算・現在値を表示する。確定済みイベントを読み取る表示であり、独自に加点しない。

終了時の資金・人気・猫の負担と活動状態、ログの書き出し、600×480での画面操作は従来の仕組みを維持する。

## 停止・確認・保存再開

1回で最大10営業日。休業も1日として数え、営業途中から開始した場合はその日の閉店を含める。操作の間にTkのイベントループへ戻る。交流操作列の比較も一つの操作内で行うため、初回計画などではその操作が終わるまで待つことがある。

選択した目標の達成は `completed` で止まり、結果確認は通常画面に残す。併用中の別の目標が達成された場合や人気の途中段階では `goal_cleared`、人気期限切れでは `expired` で止まる。目標の結果確認待ちでは再開始せず、通常操作へ戻って結果を確認する。確認済みの最終人気結果が残っていても、本来の目標が挑戦中なら再開できるよう停止判定を修正した。

中止・閉じる・ゲーム切り替えでは予約済みのタイマーを取り消し、操作の境界で止める。目標達成・10日上限・中止などの終了時は現在の営業セーブへ保存する。未設定の保存先や保存失敗は従来の案内を使う。読み込み後も実際の交流途中・派遣中の状態から共通処理で続ける。

店舗イベント・依頼・帰還などへの回答は、[共通自動プレイヤーの回答順](HumanToCatAutoPlaySeedEvaluation.md#回答順の修正内容)を使う。店舗イベントごとに停止する新しい動作は追加しない。

## 検証

[対象別GUIテスト](../tests/test_cafe_autoplay_objectives_gui.py)の追加10件で、目標の初期選択と併存、短縮した好感度目標の達成・結果閲覧と標準の6匹・好感度80を3回の10日単位で達成、交流途中の中止と保存再開・共通プレイヤーとの状態一致、有力者派遣中の保存再開・訪問結果、標準の3人目標の10日進行、基礎営業の10日上限と目標への非介入、人気段階・期限切れでの停止と確認後再開を確認した。600×480で判断一覧と開始・中止ボタンも確認した。GUIの目標別テストでは店舗イベント確率を0にし、受け入れ依頼を外して進行を固定する。短縮ケースは好感度1匹・0.5、有力者は一人・満足度25を使い、標準ケースは6匹・80と3人の条件を維持する。

Xvfb上でおまかせ画面の2ファイル21件が成功（GUI18件・共通3件）。関連するCLI・目標の32件中31件成功、別のGUI1件はスキップ。合計52件成功・1件スキップ。既存の人気の各段階・期限切れ・経営終了・中止・タイマー取り消し・保存失敗・ログ書き出しも成功した。全体テストと通常条件の10シード評価は再実行していない。

```bash
CAT_CAFE_TEST_GUI=1 xvfb-run -a python3 -m unittest discover -s tests -p 'test_cafe_autoplay*gui.py' -v
python3 -m unittest discover -s tests -p 'test_cafe_autoplay_objectives.py'
```
