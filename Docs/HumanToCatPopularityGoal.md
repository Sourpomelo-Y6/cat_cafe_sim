「営業 → 人気の成長 → 目標達成 → 継続営業」を通す初期実装。
[クリア案（1）](HumanToCatPlannedFeatures.md)を3段階に拡張した。細かな目標値・期限の調整は後続。既存セーブで開始済みの単段階目標は、その設定を維持する。

## ルール

| 項目 | 暫定値・扱い |
|---|---|
| 人気の初期値 | 経営ルールの100を維持。目標開始時には補充しない |
| 人気上限 | 目標導入後は300。未導入の旧営業は従来の100 |
| 接客による獲得 | 反応による好感度変化の合計がプラスだった接客1件につき＋5 |
| 加算時点 | 閉店時にその日の完了済み接客から一度だけ加算 |
| 目標 | 第1段階150 → 第2段階225 → 第3段階300。各開始日を含む10日以内 |
| 判定 | 閉店時。獲得人気と家出の損失を反映した後の現在人気を使う |
| 休業 | 人気の獲得なし。期限の日数には含む |
| 期限内未達 | 未達結果を記録。これだけではゲームオーバーにしない |
| 結果確認後 | 達成・未達のどちらも、期限なしの継続営業を選べる |

元設定は [cafe_goal.json](../config/cafe_goal.json)、後続2段階は [cafe_goal_stages.json](../config/cafe_goal_stages.json)。開始時に設定を保存し、設定ファイルの変更を進行中の営業へ適用しない。
新規ゲームは経営ルールとともに目標を有効にする。旧セーブは読込だけでは変更せず、「目標・結果…」から準備中に任意で導入できる。
旧セーブでは経営ルールの開始が先に必要。接客成果の未保存・交流中・イベント確認待ち・ゲームオーバー中には導入できない。
一度開始した目標の解除・期限リセット・再挑戦はできない。再挑戦は別の新規ゲームで行う。

## 何を接客成果として数えるか

接客の `affinity_pending` がプラスの結果を対象とする。これは0〜100の範囲に丸める前の、反応による好感度変化の合計。
既に好感度100のお客との接客でも、好い反応が得られていれば人気を獲得できる。
反応合計が0以下の場合や、行動せず切り上げた接客、待ち時間切れで接客しなかった客は対象外。
プレイヤー交流や派遣は接客件数に含めず、人気獲得の対象にしない。
体力切れ等の終了理由だけで成功・失敗を決めず、終了までの反応合計を見る。

当日の人気は、まず `min(上限, 閉店前の人気 + 対象件数 × 5)` にする。
その後、既存の家出判定で1匹につき20減少し、下限0とする。
比較画面の「獲得人気」は上限で切り詰めた実加算値であり、家出の減少を相殺した純増ではない。
例：人気145から2件分獲得し、家出が1匹なら、155 − 20 = 135。途中で150を通過してもクリアにはしない。

## 期限・終了条件・継続

新規ゲームでは10日目の閉店までが対象。旧セーブの4日目に開始した場合は13日目まで。
営業中に目標相当の成果が出ても、閉店時の処理が完了するまでクリアしない。
期限当日の閉店でも、人気150以上なら達成を優先し、それ以外は未達を記録する。
家出等でゲームオーバー条件も成立した場合はゲームオーバーを優先し、同じ閉店でクリアを付与しない。

結果が出たら「目標・結果…」で確認するまで、次の営業・休業・翌日への操作を止める。
休業は既存仕様どおり翌日の準備へ進むため、期限日の休業では翌日の準備で未達結果を確認する。
未保存の接客結果や帰還・譲渡イベントがある場合は先に処理し、その後で「次の目標へ挑戦」または「自由に営業を続ける」を選ぶ。
画面を閉じるだけでは継続を確定しない。保存・再開後も確認待ちを保持する。

継続を選ぶと、人気の獲得・家出・費用を含む通常の経営を続ける。
達成日・未達日は変更せず、人気が再び上下しても再クリアや未達からの達成変更は行わない。
**達成後も資金0以下・人気0のゲームオーバーは有効。** 後で帰還時費用などにより終了する場合もある。
達成による追加資金・アイテムは今回追加しない。

## 次の段階への挑戦

第1・第2段階を達成すると、「次の目標へ挑戦」か「自由に営業を続ける」を選べる。自由営業の後でも、閉店結果または準備中に次の目標へ進める。
次の挑戦では資金・人気・猫・設備を引き継ぎ、期限だけをその段階の開始日から数える。目標値は人気の増加量ではなく、現在人気の到達値。

- 閉店結果から挑戦を選んだ場合：翌日を開始日として予約する。翌日へ進む操作で準備に入る。
- 準備中に挑戦を選んだ場合：当日を開始日にする。休業結果から既に翌日の準備に進んでいる場合も同様。
- 例：第1段階を4日目に達成し、閉店結果で次へ進むと、第2段階は5〜14日目。自由営業を挟み8日目の準備で始めた場合は8〜17日目。
- 開始前に次の目標値を超えていても、挑戦開始後の最初の閉店・休業終了時に判定する。
- 期限内未達の場合は自由営業へ進めるが、次の段階は解放しない。未達段階の再挑戦・期限リセットは今回追加しない。
- 第3段階達成後は全段階達成として、自由営業へ進める。第4段階はない。

次の段階を選んでも、直前の営業日の達成結果は変えない。過去段階の開始日・達成日・自由営業の選択を目標画面に残す。
新規ゲームとこれから新しく導入する標準目標に3段階を適用する。既存の単段階セーブ・旧リプレイには後続段階を追加しない。

## 表示と保存

営業画面上部に現在人気・目標・期限日・残り日数・達成状態を表示する。
「目標・結果…」で増加条件、全3段階の目標・開始日・期限・結果と継続操作を確認できる。
営業結果の比較には、その日の人気・獲得人気・目標状態を保存して表示する。過去の結果を後日の状態に書き換えない。
経営画面の人気上限表示も導入済みなら300へ変更する。

営業セーブ形式2・チェックポイント1に任意の `goal` を追加する。
開始時設定・開始日・日別の対象件数と実加算値・達成／未達日・継続選択を保存する。
復元時は接客結果の受領記録と家出記録を使って人気と判定を照合する。表示・保存・読込だけで再加算しない。
旧セーブの過去の接客に対して人気を遡及付与しない。
3段階の設定は最初の目標導入時に固定する。現在段階の開始日と過去段階の短い結果履歴を追加し、日々の人気獲得記録は共用する。
リプレイ4は目標導入・結果確認・次段階への挑戦操作を記録し、日次加算と判定を閉店操作から再現する。

## 自由営業・好感度・有力者モードからの途中開始

[自由営業・好感度・有力者モードから人気3段階へ挑戦](HumanToCatPopularityChallenge.md)を実装。準備中に任意で開始し、店の状態・現在の人気・過去の人気獲得記録を維持する。期限は挑戦開始日から数え、追加客と増設は各段階の達成後に解放する。旧セーブの目標は自動変換しない。好感度・有力者モードでは元の目標と進捗・結果を独立して維持する。
