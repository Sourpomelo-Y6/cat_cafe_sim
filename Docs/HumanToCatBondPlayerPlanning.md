# 好感度自動交流の操作列比較・10シード評価

更新日：2026-10-03。[変更前の10シード評価](HumanToCatBondSeedEvaluation.md)では、ソラが毎セット＋2で全85セットのうち40セットを使っていた。ユーザーの依頼に沿い、猫の個性と公開ルールを使う操作選択を改善した。基準は `315f38b`。好感度の加点・一日3枠・10ターン・達成条件・猫の個性・健康係数・保存形式は変更していない。

## 判断の変更

従来は2手先までの加点を優先し、同点なら残り体力を選んでいた。種類を切り替える一手や、数ターン後にゲージを満たす操作列を評価しにくく、ソラは猫じゃらしと待機で終わっていた。

新しい操作選択は、セット終了までの操作列をコピー上で比較する。各深さで最大128候補を残す探索を使い、途中の候補は加点と関心・テンションの進捗を、保存済みの発動条件・加点値から評価する。種類の切り替え、待機とフェイントの組み合わせ、任意の心をつかむのタイミングも比較する。体力が低い時は心をつかむが可能ならそれを選び、それ以外は待機する既存の回復方針を使う。

最終比較はセットの好感度増減合計を優先し、同点なら残り体力を優先する。従来の2手先方針で終了まで進めた操作列も必ず比較対象に含めるため、探索が良い経路を落としても、その開始状態から従来方針で得る加点を下回る候補は選ばない。この保証は一つのセットの加点についてであり、累計体力・営業収益・全体の日数についてではない。上限100で切り捨てる前の加点合計を比較する点は従来どおり。

猫ID・名前を条件にせず、声かけ・見守りも同じ候補に含める。今回のソラではトンネル遊びが選ばれた。設定と初期体力・ゲージが同じ計画は128件まで再利用する。実際の操作履歴が計画と一致すれば次の操作を選び、手動操作で外れた場合は現在の状態から残りを比較する。キャッシュを失った再開でも同じ操作列を選ぶ。計画用の乱数IDは生成せず、ゲーム状態・関係データ・乱数を更新しない。

変更は好感度の安定・積極経営の交流操作に適用する。対象の猫を選ぶ順序、6匹目の加入、営業・設備投資、基礎営業、人気・有力者の経営判断は維持する。全探索や最速の保証ではない。
