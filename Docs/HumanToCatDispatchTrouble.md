# 山あいの宿への派遣と家出トラブル

更新日：2026-09-30 / 状態：初回実装済み

新規ゲームに「山あいの宿への訪問」を追加し、この派遣先だけにストレスに応じた家出トラブルを設ける。近所のお店、商店街、郊外、有力者への既存の派遣には追加しない。

## 派遣先と出発条件

| 項目 | 暫定仕様 |
| --- | --- |
| 派遣先ID | `mountain_lodge_visit` |
| 派遣先 | 山あいの宿への訪問 |
| 通常の派遣期間 | 3日 |
| 基本報酬 | 650（特性・成長補正は通常どおり） |
| 最大疲労 | 20 |
| 必要特性 | 外出好き |
| 利用開始 | 新規ゲームの開始時から、参加条件を満たせば利用可能 |

健康・在店・担当可能な状態の猫を、準備中に派遣する。従来どおり店内の席数を超える担当可能な猫が必要。出発後は接客・交流・別の派遣へ同時参加しない。新派遣先にはアイテム報酬、猫紹介、既存の固定選択イベントを付けない。

## 抽選と予告

出発時のストレスを使い、`15% + 35% × ストレス / 100` を発生率とする。範囲は15〜50%。派遣先説明、選択中の猫の参加条件、出発確認にリスクと中断後の扱いを表示する。

出発時に設定・ストレス・発生率・抽選値を固定する。抽選値は営業seedと派遣イベントIDから決まり、画面の開き直し・保存再開で変わらない。営業・休業で派遣1日目が終わった際に判定する。発生しなければ従来どおり3日分の進行後、報酬を受け取り、派遣経験を得る。

## 家出時の選択と帰還

トラブル発生時は猫が行方不明になり、派遣を中断する。案内欄の「確認する」から派遣画面へ進み、対象の「家出トラブルに対応…」を開く。回答するまで営業・日付進行を止める。

| 選択 | 費用 | 帰還 |
| --- | --- | --- |
| 捜索して連れ戻す | 100 | すぐ帰還確認待ちになる |
| 帰還を待つ | 0 | 家出した日を数えず、2日分の閉店・休業後に帰還確認待ちになる |

例：1日目の閉店で家出し、無料の帰還待ちを選ぶ → 2日目の閉店で残り1日 → 3日目の閉店で帰還確認待ち。準備中に回答しても帰還予定日は変えない。

捜索は支払い後に資金が残る場合だけ選べる。資金不足では無料の帰還待ちで進める。確認ダイアログの取消や画面を閉じただけでは回答しない。回答済みの選択は変更できず、同じ回答の再試行で二重請求しない。

帰還確認待ちは営業・日付進行を止める。派遣画面で「帰還を確認する（報酬なし）」を押すと在店へ戻り、出勤は自動設定しない。体力を最大まで戻し、ストレスは30にする。疲労・健康は保持する。

中断した派遣の報酬は0、派遣経験は加算しない。派遣先の解放に使う「派遣報酬受取回数」にも数えない。初回は派遣中の家出による人気低下と子猫費用を設けず、通常の在店猫の家出・帰還と別に記録する。在籍と飼育枠には含める。複数のトラブルや通常の家出が重なっても各件を回答・確認できる。

## 収支・履歴・保存互換

捜索費を支払った日の `dispatch_trouble_expenses` に記録し、日次支出へ1回だけ加算する。「営業結果の比較」の「派遣捜索費」、派遣結果の中断・報酬取消・対応・捜索費、猫のできごと履歴へ表示する。

新規開始時の設定と出発時の抽選条件、選択・費用・残日数・帰還確認を保存する。設定ファイルを変更しても既存ゲームには保存済みの設定を使う。詳細リプレイにも対応し、保存失敗時は確定した回答・費用を保持して再試行する。ゲームオーバー後は閲覧・保存のみ行う。

設定を持たない旧セーブには新派遣先を表示せず、自動導入しない。旧派遣へトラブルを後付けせず、既存の派遣先の条件・報酬・イベントを維持する。設定元は `config/cafe_dispatch_trouble.json`。確率・報酬・費用などの細かな調整は後続。

検証対象：発生なし・発生、捜索・無料待ち、準備中・閉店時の回答、残日数・帰還、資金境界、複数トラブルと通常家出の共存、終了後の制限、旧セーブ、候補条件・抽選固定、会計・保存失敗・詳細リプレイ、GUIの予告・取消・対応・帰還・履歴表示。
