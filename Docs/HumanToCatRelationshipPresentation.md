# 親しみの段階と再会時の表現

更新日：2026-09-13

版4の親しみを画面の描写に使う。行動効果・資金・保存形式・ログ形式は変更しない。
段階は表現上の暫定的な目安であり、成功条件や特別行動の閾値ではない。

| 親しみ | 段階 |
|---|---|
| 0以上10未満 | 距離を探っている |
| 10以上30未満 | 顔なじみ |
| 30以上60未満 | 親しみが育っている |
| 60以上100以下 | なじみの相手 |

保存済みの交流履歴がない組み合わせは「初対面」、履歴があれば親しみ0でも「再会」と表示する。
開始時の描写は保存済み親しみと現在の個性から決め、交流中に段階を越えても書き換えない。
結果には段階の前後と、段階上昇・低下・維持を表示する。未保存の結果は次回へ持ち越せると断定しない。

個性の表示分類は既存の好みから求める。触れ合い（pet/brush）、静かな交流（voice/presence）、遊び（他4種）の平均が単独で最大の分類を使う。
同率なら中立。遊び優位でgentleがactiveより高い場合は繊細な遊び好き、それ以外は活発な遊び好きとする。
これは描写の選択だけに使い、プリセット名に依存しないためカスタム個性にも適用できる。

例えば「なじみの相手」でも、甘えん坊は自分からそばへ寄り、距離を大切にする猫は少し離れたお気に入りの場所でくつろぐ。
親しみが高くても、すべての猫が触られることを好む描写にはしない。初対面でも好みの違いを表現する。

GUIの状態欄に開始時の様子を表示し、終了結果には段階の変化を追加する。
CLIの交流ログと関係データに描写文は保存せず、既存ログの再生と成果の計算を維持する。

## 実装と確認

`cat_cafe_sim/relationship_presentation.py`に表示用の段階・個性分類・描写をまとめ、版4の画面と結果表示から使用する。
通常テスト175件と画面専用6件、計181件が成功。段階の境界、5個性の違い、親しみ0の再会、開始時描写の固定、結果の上下・維持・未保存表示、表示によってログが変わらないことを確認した。
実際のTkウィジェットで初対面・再会・相手切り替えの表示を確認した。目視によるレイアウト評価は含まない。
