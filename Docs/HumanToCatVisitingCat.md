# 店先に通う猫との交流・加入

更新日：2026-09-30 / 状態：固定1匹、任意の交流と加入、保存・リプレイまで実装済み

人気第1段階の達成後、店先に通う猫と少しずつ交流し、慣れたら迎えられる。場所を探し回るスカウトとは別の加入経路。[加入計画](HumanToCatRecruitmentPlan.md)と[飼育枠](HumanToCatHousing.md)を参照。

## 出現と候補

新規ゲームの全モードで候補と必要回数を開始時に固定する。人気第1段階を期限内に達成した翌日の準備から、固定1匹のココが店先に現れる。自由営業・好感度・有力者モードは、[途中からの人気挑戦](HumanToCatPopularityChallenge.md)を開始し、その第1段階を達成した後が対象。人気集計だけの状態では出現しない。達成当日には会えず、初回出現後は人気が下がっても交流・加入の進捗を維持する。

設定は [cafe_visiting_cat.json](../config/cafe_visiting_cat.json)。初回候補は「距離を大切にする猫」の個性、キジトラ・短毛、のんびり屋の特性を持つココ。必要交流は3回、迎える費用は200の暫定値。候補・個性・特徴・特性・費用を開始時に展開して保存し、再開時に外部設定を読み直して変更しない。

## 操作と日次の進捗

「準備・お店」→「店先に通う猫…」で情報・回数・飼育枠・費用を確認する。

- 営業準備中に「交流する」を選び、確認すると進捗が1増える。1日1回まで。営業の時計を進めず、資金・人気・常連度・所属猫の体調を変えない。
- 「今日は見送る」を確認すると、その日は交流済みと同じく再交流を止め、進捗は増減しない。翌日の準備から再開できる。
- 画面を開く／閉じる、確認を取り消す、何もせず営業・休業へ進む場合は進捗と履歴を変えない。日数だけでは交流回数は増えない。
- 3回交流すると「迎える」を選べる。その日のうちに迎えても、後日まで待ってもよい。3回を超える交流や、別の候補の補充は行わない。
- 飼育枠・資金が足りなければ、進捗3回を保持して後日の準備中に迎えられる。画面内から飼育スペースを拡張して、空き枠・残金を再判定する。

店先の猫は任意の準備項目であり、交流や加入を済ませるまで営業を止める確認待ちにはしない。他の帰還・依頼・成長・店舗イベント・目標結果などの確認待ち、プレイヤー交流中、接客結果の保存再試行待ち、営業中・閉店後・ゲームオーバー中は交流・見送り・加入を行えない。休業を選ぶ前の準備中には交流できる。

## 加入と既存機能

迎える前は所属猫、飼育枠、出勤・休養・派遣、好感度6匹目標の対象に含めない。店先の交流回数は所属後のプレイヤー好感度や活動経験へ変換しない。

費用200を払った後に資金が残り、飼育枠に空きがある場合だけ迎える。加入時は健康・体力全回復、疲労・ストレス・プレイヤー好感度・活動経験0、休養予定。以後は通常の出勤・休養・派遣・プレイヤー交流と成長へ接続する。名前・個性を関係データへ登録し、特徴・特性を営業状態へ登録する。猫の詳細に加入経路・日付、できごとに店先の交流／見送りと加入を表示する。

費用は既存の受け入れ費用 `recruitment_expenses` へ一度だけ加算し、日次・期間収支で確認できる。後日の費用は0。営業ログには出現・交流回数・見送り・加入と支出を表示する。

## 保存と旧セーブ互換

営業状態の任意項目 `visiting_cat` に、固定ルール、状態、初回出現日、交流／見送りの日付と選択、加入日を保存する。状態は `untriggered` → `visiting` → `ready` → `accepted`。交流・見送りは日付順に最大1件ずつ、交流回数から状態を検証する。

新規開始時の `initialize_visiting_cat` と日々の `resolve_visiting_cat` 操作を詳細リプレイへ記録する。出現は翌日進行に接続する。出現前・交流途中・迎えられる状態・加入後・加入猫の接客途中を保存・再開でき、再開だけで交流・課金・登録を繰り返さない。

加入ではコピーした営業状態を検証し、関係データの書き込みが成功してから状態を確定する。書き込み失敗時は費用・所属・進捗を変更せず、再試行できる。加入済みの「迎える」を再実行しても二重登録・再課金しない。チェックポイント保存だけが失敗した場合は起動中の進捗・加入結果を保ち、保存を再試行する。

旧セーブ・旧ログには店先の猫を後付けせず、人気挑戦を途中開始しても旧ゲームへ自動導入しない。既存の加入経路と猫IDを維持し、店先の猫IDを候補生成・他の加入経路でも予約して重複を拒否する。読み込み時は人気達成・出現日・1日1回・必要回数・加入日・猫名簿・個性・特徴・特性・資金と照合する。

複数の通い猫、抽選出現、出現期限・離脱、交流方法による相性や進捗差、加入前の体調・好感度管理は後続。初回は確定した1匹と日ごとの交流判断に絞る。

検証結果：追加14件成功、仮想ディスプレイでGUIを含む全844件成功（174.313秒）。ローカルリンク868件と差分チェックも成功。
