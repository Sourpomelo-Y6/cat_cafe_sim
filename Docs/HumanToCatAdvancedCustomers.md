# 人気目標達成で解放する高難度のお客さん

更新日：2026-09-28 / 状態：1種類を初回実装

## 対象と解放

新規ゲームで「人気3段階」を選んだ場合に導入する。
第1段階をクリアすると「白猫好きのこだわり客」を解放し、達成日の翌日から、営業する日は1名が開店時（進行0）に来店する。
既存のお客さんの曜日・時刻・人数を変えず追加する。休業日は来店しない。
人気第1段階の達成は途中の目標達成であり、共通クリア結果画面に残る最終段階のクリアとは区別する。

次の人気目標への挑戦・自由営業のどちらを選んでも解放を維持する。人気が下がった場合や後続段階の期限内未達でも再びロックしない。
第1段階の期限内未達では解放しない。従来どおりゲームオーバーを目標達成より優先し、解放によって終了後の営業を再開できるようにはしない。

旧セーブへの後付けはしない。旧ゲームで人気目標を後から始めた場合や、有力者・好感度・自由営業で始めた新規ゲームにも初回は導入しない。
別の新規ゲームには解放を引き継がず、第1段階から挑戦する。他モードでの解放経路、第2・最終段階の追加客層、特別予約は後続。

## 満足条件と料金

| 項目 | 初回仕様 |
| --- | --- |
| お客さんID | `advanced-white`（毎回同じIDで来店回数・猫との親しみを維持） |
| 好み | 白猫。通常客の好み候補や乱数と独立して固定 |
| 条件1 | 担当猫が特徴 `white` を持つ |
| 条件2 | 今回の交流中に「心をつかむ」が1回以上発動する |
| 達成報酬 | 両方を満たした場合に追加料金100（暫定） |

通常の好み一致によるテンション補正を使う。交流コマンドは引き続き自動で、プレイヤーは担当猫と席を決める。
自動配置は従来の体力優先のままなので、必ず白猫を割り当てるとは限らない。
初期猫のソラや保護猫候補のハルなどが白猫に該当するが、白猫を選ぶだけでは条件2を満たしたことにはならない。

判定は交流終了時の1回。条件達成なら、時間料金・既存の特別行動ボーナスに追加料金を上乗せする。
条件未達でも通常料金は維持し、追加の罰金・不満・人気減少は付けない。
未接客のまま列満員・待機期限・閉店で退店した場合は追加料金0で、満足条件の達成にも数えない。
閉店による交流終了や検証用の手動切り上げでも、それまでの成果で同じ判定を行う。
「心をつかむ」の予約だけで未発動の場合は回数に含めない。

独立した満足ゲージは追加せず、「特徴一致と特別行動の実績」という接客評価の初回基盤とする。
高難度客による追加人気・アイテムは未導入。既存の接客成果による閉店時の人気加算は従来どおり。
1回の接客の満足条件、猫から客への親しみ、ゲーム全体のクリア、有力者への派遣満足度は別に扱う。

## 画面と確認手順

1. 新規ゲームで「人気3段階」を選ぶ。開始画面・人気目標画面で解放条件を確認できる。
2. 「準備・お店」→「お客さんの名簿・来店予定…」からこだわり客を選ぶ。解放前でも条件と猫の相性を比較できる。
3. 第1段階達成後、解放の営業ログと翌日の来店予定を確認する。結果確認後に継続する。
4. 白猫を出勤させて担当に選び、自動交流を進める。会計ログに条件の達成・未達、特徴一致、発動回数、追加料金を表示する。
5. 名簿でも直近の接客評価を確認できる。接客したことがない場合はその旨を表示する。直近の接客評価は、今回未接客だった場合の退店評価とは区別する。

主画面に新たな常設パネルは追加せず、既存のログ・名簿・人気目標画面を使う。

## 保存と互換

`config/cafe_advanced_customers.json` の条件・報酬を新規開始時に `advanced_customers` として固定する。保存再開時は設定ファイルを読み直さない。
解放日は保存済みの人気目標の達成日・段階履歴から導出するため、段階を進めても失われない。
来店IDを既存の日次実績に記録し、条件評価は既存の交流成果から導出する。毎ターンのログや重複する評価履歴を営業セーブに追加しない。

報酬は既存の会計・日次売上・ボーナスへ反映し、閉店後や保存再開後に再付与しない。
保存失敗後も会計結果を保持して再試行する。導入操作を詳細リプレイに記録し、旧セーブ・旧リプレイには自動導入しない。
来店予定と実績、好み、目標、追加料金と接客成果の整合性を読み込み時に検証する。

## 検証

第1段階達成前後・次段階への移行・自由営業・人気低下時の解放判定、休業、1席／複数席での会計、白猫の加入から自動交流による達成、特徴不一致・未発動・未接客、保存失敗と再試行、途中保存・翌日保存・詳細リプレイ、他モードと旧セーブの互換を確認する。
GUIは名簿660×520と人気目標500×400で、条件・直近結果・一覧とボタンを確認する。
