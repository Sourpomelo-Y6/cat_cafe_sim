# 好感度・有力者目標の自動プレイ検証

有力者の新規設定は3人へ拡張しました。[現在の達成要件](HumanToCatPatronMembers.md)と[10シード評価](HumanToCatPatronMembersSeedEvaluation.md)、[現在の有力者向け自動プレイと改善比較](HumanToCatAutoPlayPatronSafeLoad.md)を参照。以下の有力者一人・8日達成は拡張前の履歴で、旧セーブの経路として維持します。

更新日：2026-10-03。人気以外の達成条件を検証するため、共通自動プレイヤーとCLIに検証対象の選択を追加した。人気条件・期限・好感度増加量・交流枠・派遣報酬・満足度・保存形式は変更しない。

## 対象と操作

CLIの `--objective popularity|bond|patron` で検証対象を指定する。既定は従来の人気。新規開始では指定モードの通常ゲームを作り、再開では保存済みの目標を使う。再開時も検証対象を明示する。目標がないセーブには後付けせず進行不能で止まる。

```bash
python3 -m cat_cafe_sim.cafe_autoplay --objective bond --mode clear --days 60 --directory reports/autoplay_bond
python3 -m cat_cafe_sim.cafe_autoplay --objective patron --mode clear --days 60 --directory reports/autoplay_patron
python3 -m cat_cafe_sim.cafe_autoplay --objective bond --mode clear --resume reports/autoplay_bond/開始日時/cafe.json
```

日本語の操作ログに受け入れ・交流・派遣・帰還と日次の目標進捗を表示し、`--detailed` で通常操作と結果を追える。名前は加入後の猫も現在のプロフィールを参照する。CLIは通常どおり各操作後に保存し、中断・操作上限・日数上限は次の操作前に確認する。関係データも更新するため、検証には専用の新規フォルダを使う。

基礎営業は従来どおり出勤・休養と必要な回答だけを行い、目標のための新規加入・プレイヤー交流・有力者派遣は増やさない。安定経営・積極経営は選択した目標の操作を追加する。

好感度は通常の「6匹との好感度80」を使う。在籍数が不足している場合、飼育枠と運営予備資金を確認し、保護猫候補を開いて通常操作で受け入れる。初期5匹なら1匹追加する。未達の健康な在店猫を好感度の低い順・ID順で選び、1日3セット・1セット10行動の通常交流枠を使う。公開された交流状態・個性・ルールでセット終了までの候補操作列をコピー上で比較し、好感度増加を優先し、同点では体力残量と固定候補順で選ぶ。各深さ128候補と従来の2手先経路を併用する。[操作列と比較](HumanToCatBondPlayerPlanning.md)を参照。体力20以下では休憩、心を通わせる必須・可能状態ではその行動を優先する。コピー上の比較は実状態・関係データ・乱数・ファイルを変更しない。交流を終えたら通常の営業判断へ戻る。

有力者は保存済みの満足度100・基本加算25・2日の訪問を使う。同時に進める訪問は1件とし、帰還確認後に次を派遣する。健康・在店・疲労・体力・席数を超える担当可能猫数など、通常の派遣可否を確認し、疲労の低い順・ID順で選ぶ。派遣に必要な余剰猫を維持するため、この検証経路では設備・席への投資を追加せず、通常の出勤・休養判断で営業する。歓迎条件の加算も既存処理を使う。両経営方針で同じ有力者経路を使い、最速化や多重派遣は今回の対象にしない。

標準の好感度6匹を対象にする初版であり、独自目標が飼育枠を超える場合の自動拡張や、候補の最適な個性選択は行わない。資金・枠が不足する日は加入を見送り営業を続けるため、独自条件での達成を保証しない。

## 停止と人気挑戦との併存

検証対象の達成時は `completed` で停止し、その目標の結果確認はユーザーに残す。経営終了は先に停止する。好感度・有力者には期限がなく、未達のまま指定日数を使うと `day_limit` となる。日数は実行開始後に完了した営業・休業の日数で、準備中の達成日とは1日ずれる場合がある。

人気への途中挑戦は通常操作で始める。自動プレイから勝手には開始しない。途中挑戦の人気期限切れは `expired` として停止し、本来の目標・進捗を失わない。通常操作で人気の結果を確認してから好感度・有力者の検証を再開できる。人気を検証対象にした場合は従来どおり人気の期限切れで停止する。

人気段階の達成では次へ進み、最終人気の達成を確認した後も本来の検証対象が未達なら継続する。`stop_on_goal=True` では途中の人気段階でも止める。最終人気と本来の目標の成果・継続状態は個別に保存する。

GUI「10日間おまかせ」は従来の人気対象・操作条件を維持する。好感度・有力者だけのゲームをGUIから開始する対応、人気評価CLIの集計形式への他目標の追加、複数方針の比較と数値のバランス調整は後続。安定経営の好感度・有力者10シード評価は実施済みで、各評価資料を参照。

好感度は後続の[10シード評価](HumanToCatBondSeedEvaluation.md)で全シード29日目に達成し、加入・交流配分・健康と経営を確認した。以下の単一シード値は初回確認時の記録。
