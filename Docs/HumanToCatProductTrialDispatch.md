# 猫用品の体験会への派遣

更新日：2026-10-01 / 状態：初回実装済み。数値は暫定。

[働き者](HumanToCatTraits.md)の猫を接客と派遣のどちらに配置するか選べる新しい派遣先です。新規ゲームの全モードへ追加します。

## 解放と参加条件

| 項目 | 仕様 |
| --- | --- |
| 派遣先ID / 名前 | `cat_product_trial` / 猫用品の体験会 |
| 解放条件 | 人気120以上、派遣報酬を1回以上受取 |
| 期間 | 2日 |
| 基本報酬 | 300（派遣全体） |
| 必要特性 | 働き者（保存済みID `hardworking`） |
| 疲労上限 | 40以下。同じ値まで参加可能 |

出発・帰還待ち・重複受取は解放の受取回数に数えず、報酬なしの中断帰還も除きます。一度解放すれば人気が下がっても維持します。

準備中の健康で担当可能な在店猫が対象です。席数を超える担当可能な猫が必要です。同じ猫の二重派遣・同日再派遣、未解決イベント・未保存結果・プレイヤー交流中、営業中・閉店後・ゲームオーバーの出発制限は[共通の派遣仕様](HumanToCatCafeActivities.md)を使います。通常の初期猫へ働き者を追加せず、5回目の保護猫紹介からナギを受け入れて参加できます。

## 専用の追加体験イベント

出発確認で予告し、1日目終了時に「追加の用品体験をお願いされました」が一度だけ発生します。イベントIDは `extra_product_trial`、この派遣先だけが対象です。回答まで営業・翌日・休業などの進行を止めます。

| 選択 | 帰還報酬の増減 | 回答時の疲労 | 回答時のストレス |
| --- | ---: | ---: | ---: |
| 追加体験に参加する | ＋100 | ＋10 | ＋10 |
| 予定どおり終える | 0 | 0 | 0 |

期間は両方とも2日のままです。疲労・ストレスは回答時に一度だけ固定加算し、既存の上限・下限に収めます。働き者の接客疲労0.75倍・接客ストレス1.25倍をイベントに掛けません。派遣中は在店の休養回復を受けません。

追加報酬は回答時に入金せず、特性・成長補正済みの基本報酬へ100を加え、帰還受取時に一度だけ精算します。成長なしは参加400／通常終了300、派遣得意なら300×1.1＋100＝430／300×1.1＝330です。働き者の派遣倍率は1で、帰還時の追加ストレスは0です。資金・日次収支の派遣収入・派遣経験に反映し、再回答・二重受取で増えません。

新しい歓迎条件・アイテム報酬・猫紹介・家出トラブルは設定しません。

## 表示と保存互換

派遣画面に解放条件・参加条件と理由・日数・報酬、営業ログに解放を表示します。[派遣先比較](HumanToCatDispatchComparison.md)では基本報酬と両選択の報酬・疲労・ストレスを確認できます。出発確認・出来事の回答・帰還内訳・履歴も既存の画面で対応します。閲覧・取消は状態を変更しません。

開始時に [解放・派遣先設定](../config/cafe_dispatch_unlocks.json) を任意項目 `dispatch_unlocks.rules.cat_product_trial` に固定し、出発時に [イベント設定](../config/cafe_dispatch_encounters.json) を既存の `encounter` へ固定します。再開・詳細リプレイで現在の設定を読み直しません。

体験会の設定がない旧セーブには派遣先を後付けせず、既存派遣先・出発済み記録・旧ログを維持します。働き者の猫がいても、旧ゲームには体験会を追加しません。営業セーブ形式2・チェックポイント1・詳細リプレイ4を維持します。出発直後・回答待ち・回答済み・帰還待ち・受取後を保存再開できます。保存失敗後の再試行で負担・報酬を二重処理しません。
