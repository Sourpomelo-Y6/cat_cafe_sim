# Unity 譲渡済み猫の表示切替

猫一覧と営業準備に「譲渡済みも表示」を追加しました。Pythonの `visible_cat_ids` と同じく、初期状態は譲渡済みを非表示、ONにすると全ての猫を表示します。派遣中・行方不明・療養中の猫は非表示対象に含めません。

## 表示と選択

二つの切替は同じゲーム画面内で連動します。通常の状態更新や日付変更では選択を保持し、別ゲームの読込・新規開始では非表示に戻ります。表示中の猫の選択はIDで維持し、選択中の猫を隠したときは表示中の先頭へ移します。全ての猫が譲渡済みの場合も空一覧を扱い、切替で履歴を見返せます。

猫カード・全体の猫選択・営業準備の選択欄と一覧を同じ条件で絞ります。選択欄の表示位置から猫IDを対応させるため、非表示の猫に出勤操作を送信しません。譲渡済みの猫は表示しても出勤できません。選択した譲渡済み猫の詳細画面を非表示切替で閉じます。

## 記録と営業設定

切替はUnity内の閲覧設定です。猫のデータや過去の交流・譲渡記録、出勤設定、休養案、保存形式を変更せず、Pythonにゲーム操作を送信しません。表示をONに戻し、猫カードの詳細から過去の記録を閲覧できます。

## 確認

- Unityで譲渡済みだけの絞り込み、二つの切替の同期、表示位置とIDの対応、選択の保持と移動、詳細履歴、全件非表示、休養案の保持、未接続時の操作制限、新規ゲームの初期化を確認。
- 実際の譲渡データを使うPlayモードで切替・履歴閲覧と、絞り込み後の猫に出勤/休養操作を送るHTTP連携を確認。切替で状態の版が変わらず、元ファイルも変更しないことを確認。
- Pythonの既存表示条件・譲渡・猫履歴テストは10件成功、画面環境が必要な10件はスキップ。
- 猫一覧・営業準備・実データの画面を撮影して配置を確認。
