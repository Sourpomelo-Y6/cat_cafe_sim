# 選んだ猫の派遣先比較

更新日：2026-10-01 / 状態：比較画面と出発確認への接続を実装済み

派遣先が増えたため、選んだ猫の参加条件・報酬・負担を一覧で比べます。「準備・お店」→「派遣・帰還を確認する…」で猫を選び、「派遣先を比較…」を開きます。

## 一覧と詳細

現在の派遣画面と同じ派遣先を並べます。新規開始時に保存された運動教室・読書サロン・撮影スタジオ、宿の保存設定、有力者目標を開始済みの場合の専用派遣先も使用します。対応する設定を持たない旧ゲームには追加派遣先を表示しません。基本3派遣先と今から出発する分のイベント・アイテムは、既存の出発処理と同じ設定を参照します。出発済み記録の条件を変更する画面ではありません。

| 表示 | 内容 |
| --- | --- |
| 参加可否・理由 | 準備・未解決イベント・保存待ち、解放、健康、疲労、必要特性、余剰猫など既存の出発条件 |
| 日数 | 派遣全体の日数 |
| 報酬見込み | 特性・成長補正と歓迎ボーナスを含む、選択イベント前の資金報酬 |
| 帰還ストレス | 通常帰還時の特性によるストレス加算 |
| 選択による報酬・負担 | 各選択の最終報酬、報酬増減、疲労・ストレスの固定変化 |

選んだ行の詳細に必要特性・疲労上限・解放進捗・歓迎の一致を表示します。選択効果には、現在の状態に適用した場合の疲労・ストレス前後値と上限・下限を示します。経営ルールなしの旧ゲームではストレス変化を適用しない旨を表示します。

報酬は一日あたりではなく派遣全体の額です。選択イベント前の見込みと各選択の報酬を区別し、負担の変化は固定値です。帰還時の特性ストレスとは別です。休養による回復や家出の抽選結果を予測して確定報酬として扱いません。

アイテム報酬と使用時の効果、帰還受取後の猫紹介と受け入れ費用、有力者満足度の増加量と上限も表示します。山あいの宿は現在のストレスに基づく家出確率、中断報酬0、捜索費または帰還待ち日数、中断帰還時のストレス設定値（通常帰還のストレス加算は適用しない）を詳細に示します。乱数や抽選結果は表示しません。

## 比較から出発確認

参加可能な派遣先を選び「この派遣先で出発確認…」を押すと、比較画面を閉じ、元の派遣画面の猫と派遣先を選択して既存の確認を開きます。確認の取消では猫・資金・日付・記録を変更しません。確認した場合にだけ通常の派遣処理で出発し、条件・候補・イベントを固定します。

参加不可の行も閲覧できますが、出発確認ボタンは無効です。操作直前に条件を再計算し、画面を開いた後に疲労や保存待ちなどが変わった場合も出発しません。「再確認」で一覧と詳細を更新します。猫未選択の場合は比較ボタンを無効にします。

比較画面は最小560×400、一覧は縦横スクロール、詳細は縦スクロールに対応します。閉じる／Escapeで元の派遣画面へ戻り、その画面のモーダル状態を維持します。営業は既存どおり一時停止したままです。

## 絞り込みと並び替え

「参加可能な派遣先だけ表示」で、現在出発できる行き先だけを表示します。初期状態は全件表示です。参加可能な行き先がなければ空の一覧と「絞り込みを解除すると参加不可の理由を確認できます」の案内を出し、詳細を空にして出発確認を無効にします。絞り込みを解除すると各行の参加不可理由と条件を確認できます。

並び順は「標準順」「報酬見込みが高い順」「期間が短い順」から選べます。報酬は特性・成長・歓迎補正込みで選択イベント前の派遣全体額を数値として比較します。期間は日数の昇順です。同額・同日数の場合は標準の派遣先順を維持します。各選択の報酬と負担は一覧・詳細にそのまま表示します。

表示中の選択は絞り込み・並び替え・再確認後も維持します。選択行が非表示になった場合は最初の表示行を選びます。操作直前の条件確認で全件が参加不可になった場合も、別の派遣先へ自動で出発せず案内を表示します。表示件数を全件数と合わせて示します。

絞り込み・並び順は画面内だけの設定です。開き直すと全件表示・標準順へ戻り、保存形式やゲーム数値・履歴を変更しません。最小560×400でも表示操作と出発確認・閉じるを利用できます。
