# 猫との好感度目標：6匹

## 採用した初回仕様

当初の22匹案をユーザー指定で6匹へ変更し、提案の了承を受けて初回実装した。
**プレイヤーへの好感度80以上の在籍猫が、同時に6匹以上になるとクリア**する。期限は設けない。
80は暫定値。細かなバランス調整は全体の流れを固めた後に行う。

- 在店・休養・療養・派遣中・家出中の猫を数える。
- 譲渡済みの猫は数えない。連れ帰った子猫は管理対象に加えないため対象外。
- お客さんへの親しみ、交流中の関心・テンションとは区別する。
- 人気・有力者目標と独立し、同時達成を強制しない。

## 操作と判定

1. 経営ルールが有効な営業準備中に「結果・記録」→「猫との好感度目標・結果…」を開く。
2. 条件を確認して任意で開始する。新規ゲーム・旧セーブとも自動開始しない。開始後の取り消しは設けない。
3. 猫の詳細からプレイヤー交流を行う。目標画面で各猫の好感度・所在・現在の対象判定を確認する。
4. 目標開始時と、交流が終了して好感度が確定した時点で判定する。開始時に既に条件を満たす場合は即達成する。
5. 達成時は進行を止め、案内欄の「確認する」から結果を確認する。「結果を確認して営業を続ける」で継続できる。

準備中のみ開始可能で、接客結果の保存待ち・進行中のプレイヤー交流・未解決イベント・他の目標の結果待ち・ゲームオーバー中は開始できない。
ゲームオーバーを優先し、その状態では新たなクリアや結果確認による営業再開を認めない。

達成日と達成時の対象猫IDを一度だけ記録する。継続後に好感度が下がる・譲渡するなどして現在の対象数が減っても、達成済みの結果は取り消さない。現在の対象数と達成時の猫を区別して表示する。

## 保存・互換性

設定は `config/cafe_bond_goal.json` の `target: 6`、`affinity: 80`。
開始時の設定を営業状態の任意項目 `bond_goal` に保存する。開始日・状態・達成日・継続確認・達成猫IDを含み、猫別の進捗は既存のプレイヤー好感度と活動状態から算出する。
未導入のセーブに項目を追加せず、読込だけで目標を開始しない。設定ファイルを変更しても開始済みの条件は変更しない。
営業セーブ・再開と詳細リプレイに対応し、再開によって達成イベントを重複発生させない。新しい行動履歴を追加保存しない。

## 検証

6匹・好感度80の境界、実際のコマンド交流終了での判定、既存好感度を持つ状態での開始、派遣・家出・譲渡の対象区分、ゲームオーバー優先、他目標との併用、保存再開・リプレイ、不正状態の拒否を確認する。
GUIでは開始確認の取消、進捗一覧、達成時の進行停止と案内、結果確認後の継続、最小サイズでの表示を確認する。
