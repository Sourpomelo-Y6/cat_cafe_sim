# 猫の運動教室への派遣

更新日：2026-09-30 / 状態：初回実装済み

[体力自慢](HumanToCatTraits.md)を持つ猫の新しい担当先。通常の接客と派遣で猫の配置を選べるようにする。数値は暫定。

## 解放と参加条件

新規ゲームの全モードに追加する。人気120以上かつ派遣報酬1回受取で解放し、以後は人気が下がっても維持する。出発・帰還待ち・二重受取は受取回数に数えない。派遣中断による報酬なしの帰還も除く。

| 項目 | 初回仕様 |
| --- | --- |
| 派遣先ID / 名前 | `cat_exercise_class` / 猫の運動教室 |
| 期間 | 2日 |
| 基本報酬 | 300（派遣全体の額） |
| 必要特性 | 体力自慢（保存済みID `hardy` で判定） |
| 疲労上限 | 40以下。同じ値まで参加可能 |

準備中の健康で担当可能な在店猫が対象。店内の席数を超える担当可能な猫が必要。同じ猫の二重派遣・同日再派遣は不可。未解決イベント、未保存の接客結果、プレイヤー交流中、営業中・閉店後・ゲームオーバーでは出発できない。共通の制限は[派遣仕様](HumanToCatCafeActivities.md)を参照。

## 操作と帰還

「準備・お店」→「派遣・帰還を確認する…」で行き先を選ぶ。解放条件と進捗、2日・報酬300・疲労40以下・必要特性を表示し、猫一覧と選択欄に参加可否を示す。出発の確認を取り消すと状態は変えない。

営業日・休業日のどちらも1日ずつ進む。派遣中は在店の接客・休養から外れ、疲労は回復しない。期間終了後は帰還確認待ちとなり、受取まで進行を停止する。受取で在店に戻し、資金と派遣経験を一度だけ反映する。出勤予定は自動で戻さず、準備中に選び直す。

体力自慢による派遣報酬・帰還ストレスの追加補正はない。既存の派遣得意による報酬倍率を適用し、日次収支の派遣収入と、派遣結果・内訳に表示する。猫紹介、アイテム報酬、家出トラブルは設定しない。

## 追加プログラムの選択

これから出発する運動教室の派遣には、1日目終了時に一度だけ「追加の運動プログラムに参加できます」の出来事が届く。出発確認で予告し、回答まで営業・翌日・休業を止める。期間は2日のまま。

| 選択 | 帰還報酬 | 回答時の疲労 | ストレス |
| --- | --- | --- | --- |
| 追加の運動プログラムに参加する | ＋80（基本300なら380） | ＋10 | 変化なし |
| 予定どおり終える | 追加なし（基本300） | 変化なし | 変化なし |

疲労10は固定加算で、接客疲労の特性倍率は掛けない。報酬80は回答時に入金せず、成長補正済みの基本報酬へ加え、帰還受取時に一度だけ精算する。既に出発済みの運動教室派遣には後付けしない。[派遣中の選択イベント](HumanToCatDispatchEncounters.md)を参照。

## 保存と互換性

新規開始時に `config/cafe_dispatch_unlocks.json` の運動教室の解放条件と派遣先定義を固定し、任意項目 `dispatch_unlocks.rules.cat_exercise_class` に保存する。解放日・達成時の人気と受取回数は既存の `unlocked` に記録する。出発記録には保存済みの派遣先定義を使う。選択イベントは出発時に `config/cafe_dispatch_encounters.json` から固定し、既存の任意項目 `encounter` に未発生・回答待ち・回答済みと変化前後を記録する。設定変更後も条件・日数・報酬を再読込して変更しない。

営業セーブ形式2・チェックポイント1・詳細リプレイ4を維持する。復元では派遣先定義と開始時の設定、解放前の出発、解放記録、残日数・資金・受取の整合性を確認する。保存失敗後の再保存で二重請求・二重報酬を発生させない。

旧の商店街・郊外の2件だけの解放設定と、解放ルールなしの旧セーブを読み込める。運動教室は旧ゲームへ後付けせず、一覧にも追加しない。既存派遣先、出発済み記録、山あいの宿の家出設定は維持する。

## 検証

[追加テスト](../tests/test_cafe_exercise_dispatch.py)で全モードの初期化、実接客による人気120への到達と受取の両条件、解放の維持、特性ID・疲労境界・健康・余剰猫・未保存結果、候補からの加入と出発、1席／複数席、営業・休業による2日進行、帰還報酬・経験・日次収支、二重受取、保存失敗と再試行、旧ルール・旧派遣、固定設定と詳細リプレイ、不正な設定・記録を確認する。GUIでは解放ログ・参加条件・出発確認と取消、帰還と内訳、500×400の最小サイズを確認する。

派遣先追加時の検証結果：GUIを含む全782件成功。ローカルリンク841件と差分チェックも成功。

選択イベント追加後の検証結果：GUIを含む全790件成功。ローカルリンク844件と差分チェックも成功。
