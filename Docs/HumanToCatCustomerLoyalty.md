# お客さんの常連度と週1回の追加来店

更新日：2026-09-30 / 状態：初回実装済み

## 目的と区分

良い接客を、その場の会計・人気・猫との関係だけで終わらせず、後日の来店増加へつなげる。
「猫からお客さんへの親しみ」「お客さんから店への常連度」「今回の接客条件の達成」は別の値として扱う。

常連度は新規ゲームで導入する。旧セーブには読み込み時や人気目標達成時に後付けせず、従来の来店予定を維持する。
開始時に選んだ人気・有力者・好感度・自由営業の全モードで利用できる。

## 初回ルール

| 項目 | 暫定仕様 |
| --- | --- |
| 上昇条件 | 接客評価が有効なゲームは「満足」の接客。評価未導入の旧ゲームは猫から客への親しみが実際に増えた接客 |
| 上昇量 | 1接客につき常連度＋25 |
| 上限・常連化 | 100で上限。同じ接客で100に達した日を常連化日として保存 |
| 追加来店 | 常連化日の翌日以降、本来来ない曜日のうち固定した1曜日に週1回、進行0で来店 |

対象となる1接客につき一定量を加算し、親しみの増加量の大小では変えない。接客評価が有効なら「普通・不満」は対象外で、評価未導入なら親しみが増えなかった接客は対象外。未接客の退店、待機列満員、待機期限、休業では上昇しない。
1日に同じ客を複数回接客する通常経路はないが、判定単位は接客1件とする。100到達後は追加で増やさない。

通常客の追加曜日は、保存済みの曜日パターンで本来来ない曜日から固定する。初回の奇数ID客は火曜日、偶数ID客は月曜日が追加曜日になる。
同じ営業セーブ・同じ客では変化せず、常連化した当日には追加来店しない。
休業日が追加曜日と重なった場合は来店せず、翌日への繰越来店は行わない。次の同じ追加曜日に来店する。

[高難度客](HumanToCatAdvancedCustomers.md)と[4席増設による追加客](HumanToCatExpansion.md)も同じ常連度を持つ。
これらが元の仕組みですでに毎日来店する期間は、常連の追加予定と通常予定を統合し、同じ日に2回来店させない。常連状態・常連化日・常連度は名簿に残す。

[累積不満](HumanToCatCustomerDiscontent.md)が100に達した常連客も7日間来店を停止する。常連度・常連化日・猫との親しみは維持し、復帰後に通常曜日と常連追加日の予定へ戻る。接客評価の判定は[満足評価](HumanToCatCustomerSatisfaction.md)を参照。

2026-10-02追加：[人気第1段階後に増える通常客](HumanToCatPopularCustomerGrowth.md)も同じ常連度を持つ。毎営業日の予定を優先し、常連化で同日に2回来店させたり、定期枠を開店時へ移動したりしない。

## 画面と操作

「準備・お店」→「お客さんの名簿・来店予定…」に常連度の列を追加する。
未達は `25/100` のように表示し、達成後は `100/100・常連` と表示する。
お客さんを選ぶと、常連化日と追加曜日を含む来店曜日を確認できる。今日／翌日の予定切り替えにも追加来店を反映する。

接客終了時には営業ログへ常連度の増加を表示し、初めて上限へ到達した場合は「常連になりました」と示す。
名簿の閲覧や今日／翌日の切り替えでは、常連度・来店実績・時間・関係データを変更しない。

## 保存・再開・互換

`config/cafe_customer_loyalty.json` の上昇量と必要値を新規開始時に営業セーブへ固定する。再開時は設定ファイルを読み直さない。
客ごとに現在値と常連化日だけを保存し、毎回の常連度履歴や毎ターンの接客ログは追加しない。
常連度は保存済みの接客成果と照合し、常連化前の日に追加来店していないことも曜日予定・来店実績の検証に含める。

接客終了後の保存失敗では、常連度と会計・接客成果を保持して保存を再試行する。再開による再加算や追加客の二重生成を行わない。
初期化操作を詳細リプレイに記録する。常連度項目のない旧セーブ・旧リプレイは従来どおり読み込む。

## 確認

親しみ増加あり／なし、25・100の境界、常連化当日と翌日、通常曜日との重複防止、週の循環、休業、未接客退店、高難度客・増設客、今日／翌日の名簿、途中保存・翌日保存・保存失敗、詳細リプレイ、破損データ、旧セーブ互換を確認する。
GUIは名簿の最小サイズ660×520で、常連度・追加曜日・予定・猫一覧がスクロールを含めて操作できることを確認する。

## 常連からの猫紹介

新規ゲームでは、最初に常連になったお客さんから翌日の準備中に[猫紹介](HumanToCatRegularIntroduction.md)が一度だけ届く。固定1匹を費用200で迎えるか、費用・人気・常連度を変えずに見送る。既存の常連化・週1回来店を維持し、旧セーブには後付けしない。
