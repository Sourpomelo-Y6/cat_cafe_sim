# 未着手機能と検討事項

更新日：2026-10-01 / 状態：後続候補。実装順・未指定の数値は未確定

実装済み機能は[全体計画](HumanToCatGameFlowPlan.md)へ集約しました。本書には初回範囲を超える候補だけを残します。原案の「未決定」は当時の状態なので、現在の未着手項目とは区別します。ユーザーの提示案・修正と当時の論点は[整理前の記録](History/2026-09-30/HumanToCatPlannedFeatures.md)に保存しています。

## 開発方針

ゲーム全体の流れを先に固める方針を維持します。細かなバランス調整は従来後回しでしたが、現在は自動プレイと併せて調整したいという希望を下記に記録しています。具体的な調整範囲・数値は未確定です。スカウトはユーザー指定で低優先度です。人気目標の自動プレイCLI初版と日本語ログは実装済みです。テスト用実行・日本語ログ・将来のGUI連携案は[自動プレイ計画](HumanToCatAutoPlayPlan.md)を参照してください。次に着手する機能はユーザーの依頼に沿って決めます。

子猫は個体管理せず外部への引き渡し費用のみ扱い、6匹目標へ算入しません。お詫び費用は採用しません。通常接客のコマンドは自動で、プレイヤー交流とは別です。

## エンディングまでの自動プレイ

ユーザーはテスト用自動プレイの導入、実行内容の可視化、将来のGUIで約10日まとめて進める機能を希望しています。[会話整理と設計案](HumanToCatAutoPlayPlan.md)にまとめました。人気目標のCLI初版は実装済みで、投資・予約を使うクリア方針も実装済みで、GUI連携・新規派遣・加入の自動化は後続です。

初版の対象は人気3段階の最終結果です。その後、有力者・猫6匹の好感度を達成する操作方針へ広げる案を保持します。資金・人気のゲームオーバーは初版でも終了理由として扱います。

初版の単純な方針を `basic`（基礎営業）として維持し、予測・投資・予約を使う `clear`（クリアを目指す）を追加しました。通常設定の人気3段階を、数値変更なしで16日目にクリアすることを確認しています。両モードを比較してからバランス調整へ進む方針です。詳細は[自動プレイ計画](HumanToCatAutoPlayPlan.md#基礎営業とクリアを目指すモード)を参照してください。

必勝を初回要件とせず、一定日数内の正常な終了、進行不能の検出、終了理由の報告、途中保存・再開での結果一致を検証する案です。通常の自動接客や100日比較と役割を分けます。

## 自動プレイを使ったバランス調整

ユーザーは自動プレイに加えてバランス調整も希望しています。実行結果から資金・人気・達成日数・猫の負担・各選択肢の費用と報酬を比較する後続作業として扱います。具体的な難易度や調整範囲は未確定で、今回は数値を変更していません。[自動プレイ計画](HumanToCatAutoPlayPlan.md)に希望と検討案を記録しています。

## 追加時の共通確認

準備で判断し、一日を進め、結果を確認して次の配置へつなげる経路を確認します。選択待ちの保存再開、同じ猫への二重配置、費用・報酬・健康更新の重複、終了後の進行制限、旧セーブと詳細リプレイの互換を維持します。検証後に関連仕様と引き継ぎを更新し、コミットは別途依頼を受けて行います。
